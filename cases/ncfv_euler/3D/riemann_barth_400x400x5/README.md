## RP1 第 1290 步恢复与正性保护

原 RP1 于 2026-10-15 16:17 中止。增加非零 rank 的异常输出后，
从第 1290 步复现确认：第 1296 步后 rank 55 的重构点锚压力成为
`-0.00011012659305826841`，`EfficientSurfaceMean` 的正性保护因锚点自身
非物理而报错。Barth 系数只限制界面修正量，不能修复此前的负压点恢复值。
修复在启用限制器的高效模式下，将非物理点恢复值向守恒均值凸组合收缩。
物理点值、守恒均值、Roe 通量及 CFL 均保持原有设置。

最后原生 H5 检查点为第 1000 步，最后完整 VTK 为第 1290 步。
`recover_snapshot_restart.py` 核验全部 964,806 个节点后，将 VTK 中的
密度和守恒总能量直接保留、动量由密度乘速度恢复，写入独立 H5。
此恢复仅引入浮点舍入，压力往返误差最大约 `6.7e-16`，不裁剪状态。
恢复的物理时间为 `0.09980282772547822`。

`RP1_resume_1290.json` 为续算配置，输出到
`RP1/resume_1290_positive_anchors/`，每 30 步同时保存 VTK 与原生 H5。
`resume_rp1.py` 保存初次失败的 manifest、启动续算、完成后合并时序，
再等待 RP2–RP4 完成，接管最终核验和视频生成。
原 VTK、H5 和初次日志均保留。进度见 RP1 的 `run_manifest.json` 中
`active_solver_log` 指向的日志，以及根目录 `RP1_recovery_status.json`。

`limiter_audit/`，汇总为 `limiter_audit/audit_summary.json`。

`[0.1198651762,1.5445068957]`，有 2,174 个节点在系数接近零时仍保留
相对一环均值的密度越界；其中内部节点也能复现。界面均值对端点点值
的既定约束检查通过。该流程限制的是恢复后的端点区间，未约束
体积均值到点值的恢复，因此正值过冲不会被先前的正性保护消除。

另确认浮点敏感性：`increment > verySmallReal` 使用的阈值为 `1e-200`。

点恢复与宏面重构的保均值限幅、低阶退化路径则需要统一设计和验证。

## 附加压力界限试验

`RP1_pressure_zperiodic_tol1e10.json` 保留 z 周期、Roe、CFL=0.5、保正和
守恒分量 `1e-10` 判零策略，额外设置 `reconstruction.limitPressure=true`。
以一环均值压力为上下界，压力检查覆盖恢复点及宏面完整候选状态，继续
收缩原公共系数；不裁剪守恒均值或直接改写压力。界限容差为
`1e-10*max(1,abs(p_min),abs(p_max))`。

`run_pressure_limiter_tests.py` 冻结同一生产二进制，在 40×40×5、z 周期
小网格上分别运行 RP1 和一维平面激波的压力开关对照，均推进到 t=0.25。
每对仅修改 `limitPressure`，写入原生 H5、指标 JSON/CSV 和密度/压力对照图，
不使用侵入式通量诊断开关。独立结果位于
`data/out/NCFV/pressure_limiter_tests/`，完整网格配置输出路径为
`data/out/NCFV/riemann_barth_400x400x5_pressure_zperiodic_tol1e10/`。

2026-10-26 的 4 组对照见 `pressure_limiter_tests/20261026_120750/`。
RP1 终态界面压力邻界越界数从 1022 降至 0（审计容差 1e-9），但密度展向差
从 0.147923 增至 0.168204，压力展向差从 0.149469 增至 0.159097。
平面激波密度过冲降低约 8%，但展向差仍未改善。此试验说明附加压力约束
按预期生效，却不能单独保证无振荡；这里没有启动完整网格压力限幅重算。

## 通用三维限制策略对照（2026-10-26）

`run_limiter_strategy_tests.py` 冻结各次实际程序与源码，比较 RP1、平面
激波、全周期接触输运和 20/40 网格光滑熵波。RP1/平面激波采用
40×40×5、z 周期、CFL=0.5、SSPRK3、t=0.25、4 MPI ranks；熵波和接触
使用全周期边界及精确双体积均值，以避免把出口误差当作限制器耗散。
汇总及固定蓝红色标、25 级等值线图位于
`data/out/NCFV/limiter_strategy_tests/20261026_summary/`。

所有保留候选都不修改任何坐标方向的导数。早期按坐标判别后清零导数的
试验已按用户要求从主程序、配置和 schema 移除；冻结历史记录仅用于诊断，
不列入推荐方案。完整邻接环只修改几何模板选择，对三维问题同样适用。

| 方案 | RP1 密度最大展向差 | 实测结论 |
|---|---:|---|
| 原均值 Barth | 0.147923 | 仍有明显展向污染 |
| Barth + 压力界限 | 0.168204 | 压力界限生效，但整体污染未改善 |
| 状态界面双端均值界限 | 1.35872e-6 | 展向差很小，但平面激波压力过冲未改善、密度 L1 增大约 37% |
| Barth + 完整通量限制 | 0.0527264 | 有改善，仍未消除展向差 |
| 仅完整通量限制 + 必要保正 | 0.00465388 | 较原 Barth 降低约 96.9%，仍非严格二维保持 |
| 严格配对通量界限、关闭 Barth | 0.0461869 | 更耗散且展向差反而更大 |
| 完整邻接环 + Barth | 0.137709 | 单纯模板完整化没有解决问题 |
| 完整邻接环 + 仅通量限制 | 0.00614670 | 未优于紧致模板的仅通量限制 |
| 一阶 LLF | 8.88e-16 | 展向差为舍入量级，接触明显变厚 |

仅完整通量限制在平面激波上将远离声学间断处的压力过冲从 0.00893131
降为 0.000383706（降低 95.7%），但密度 L1 从 0.0158536 增至 0.0171720。
全周期光滑波 40 网格密度 L1 从 0.000240399 降为 0.000166458；20→40
观测阶约 2.26。严格配对通量界限的观测阶约 0.95，误差和耗散代价明显。
纯一阶 LLF 的周期接触 L1 为 0.130993，原 Barth 为 0.0218524，不能将其
低展向误差解释成兼顾高分辨率的解决方案。

`run_true3d_limiter_tests.py` 另外完成 16 组真正三维测试：20³ 全周期
光滑波 `rho=1+0.2 sin(2pi(x+y+z))`，速度为 `(0.3,0.2,0.1)`，t=0.25；
以及法向 `(1,2,3)/sqrt(14)`、t=0.05 的斜激波。初值及真解均为双体积
均值；斜激波以立方体投影的解析 8 项 CDF 积分，误差只统计内部
`[0.2,0.8]^3`，不把边界过冲误作内部激波振荡。结果汇总位于
`data/out/NCFV/true3d_limiter_tests/20261026_complete20/combined_summary.json`。

三维光滑波中，仅通量限制与 Barth 的 L1 接近（增加 0.59%），真实 w=0.1、
压力与总守恒量保持至舍入级；但三维斜激波密度 L1 从 0.02616 增至
0.04141，切向速度误差也增大。严格配对通量界限的三维光滑误差约为原
Barth 的 12 倍。因此仅通量限制是 RP1 上有价值的实验候选，尚不是普遍
优于原方法的三维默认方案；这里也没有进行三维网格收敛证明。

独立 `audit_flux_strategy.cpp` 对最终状态重建原高阶通量、LLF 通量及
两端修正 bar，核对真实共享系数和完整前向 Euler 更新；结果见
`data/out/NCFV/flux_strategy_audit/`。已审候选满足所定义的分量界限和
正密度/正压力，内部通量守恒闭合为约 1e-15，说明残余振荡不是因为漏乘
系数或边界界限未实际启用。每个 RK 子步的实际凸 CFL 条件也由程序检查。

这些结果表明：状态/压力局部界限不等价于完整高阶更新的多维稳定性，
扩大模板或继续收紧公共系数也不保证改善。下一步应验证按特征波或熵
控制的激波局部通量回退，避免所有波共用过强限幅；本轮没有证明一套
同时彻底消振并保留三维分辨率的新策略。所有新增策略默认关闭，旧输出
及用户配置保留，尚未以这些新策略重算 400×400×5。

初态几何对照进一步区分了这两个问题：紧致模板的原始
`max(abs(dz rho))=0.2389167`，完整邻接环在未改写导数的情况下自然降至
`4.03e-15`，但终态展向污染仍为 0.137709。原初态点值的层间差已约为
`2.22e-16`，错误 z 梯度可在各层同样出现。因此模板的伪 z 导数确实存在，
却不是终态振荡的充分解释；完整非线性高阶更新的横向稳定性仍需独立
解决。独立证据见
`data/out/NCFV/flux_strategy_audit/initial_ring_comparison/comparison_summary.json`。

## 严格二维输入的三维重构导数诊断

`audit_reconstruction_dz.cpp` 直接把独立标量双体积均值送入
`Reconstruction::ComputeCoefficients`，不经过 Riemann 求解、限制器或时间
推进。12 组试验覆盖 20/40/80×同阶×5 网格、紧致/完整环、单/四 MPI
进程和真正三维二次场。所有二维输入在相同 (x,y) 柱上的均值差严格为零；
网格沿 z 挤出，Lz=5h，保持立方单元。结果位于
`data/out/NCFV/reconstruction_dz_diagnostic/20261026/summary.json`。

40×40×5 的最大绝对原始 z 导数为：

| 精确双体积均值输入 | 紧致 16 点模板 | 完整邻接环 |
|---|---:|---:|
| 常数 | 0 | 0 |
| 二维线性函数 | 5.27e-16 | 1.32e-16 |
| 含 xy 的二维二次函数 | 1.93e-15 | 5.38e-16 |
| sin(2πx)cos(2πy) | 0.00640670 | 1.93e-15 |
| RP1 密度 | 0.238917 | 4.59e-15 |

因此问题来自对非二次数据的离散维度保持性，而不是 z 输入发生变化或
求导方向索引错误。真正三维的 z、xz、yz、z² 及混合二次场仍得到正确
梯度，最大误差为 9.04e-14；单/四进程的二维最大导数统计差不超过
6.11e-16。二维光滑输入的假 z 导数在 N=20/40/80 时分别为
0.0250006/0.00640670/0.00161159，观测阶约 1.96/1.99；RP1 则为
0.119458/0.238917/0.477833，每次细化翻倍。间断处的这种耦合不会通过
简单加密在最大范数下消失。

独立 `audit_z_column_actual.cpp` 定位到内部原始节点 4201，坐标
(0.475,0.5,0.05)。该紧致模板虽含全部整体反向点 r↔−r，却缺少两个
独立 z 镜像点；同一 (x,y) 柱的 z 求导权重和最大为 1.6666667。对任意
z 不变数据，重构导数可按柱分组为

\[
D_z q_i=\sum_C s_{iC}\bar q_C,
\qquad s_{iC}=\sum_{j\in C}w^z_{ij},
\]

其中目标节点系数 −Σw 也计入目标柱。任意二维数据精确消去的必要充分
条件是每一个 s_iC 都为零；二次多项式精确只给出有限个矩条件，不能
替代这个逐柱条件。该节点的实际假导数可直接化为

\[
D_z q_{\rm flat}
=\frac{\delta_{xx}q(y-h)-\delta_{xx}q(y+h)}{48h},
\quad
\delta_{xx}q(y)=q(x-h,y)-2q(x,y)+q(x+h,y).
\]

RP1 两排未除 h² 的二阶差分别为 0.19715、0.48385，代入 h=0.025 即得
−0.2389166667，与实际梯度相差不足 4e-16。对光滑函数，该项首项为
−h²*q_xxy/24：三维紧致拟合把 x/y 高阶残差投影到了 z 线性项。
完整环在同节点的逐柱权重和降至 1.78e-15，原始 z 密度导数自然为
−8.92e-16，没有修改任何求导结果。具体配对、权重与复现命令见
`data/out/NCFV/z_column_actual_audit/comparison_summary.json`。

`analyze_dz_primitives.py` 还用冻结 RP1 守恒梯度核对速度与压力链式导数：
紧致模板 max|p_z|=0.486622，完整环为 4.74e-15，说明原始守恒梯度的
泄漏会传到物理量导数；这不是新增的原始变量转换错误。
`plot_dz_origin.py` 生成逐柱权重及网格尺度对照图，位于
`data/out/NCFV/reconstruction_dz_origin/dz_origin.png`。

正确修复对象是几何模板与求导算子的维度保持条件，保留完整三维基函数，
而不是在计算后把 z 导数清零。完整环已在本次纯重构试验中恢复零 z
导数；时间推进的多维通量稳定性仍是独立需要解决的问题。

## 共享梯度逐界面累乘重算

`RP1_shared_gradient_sweep_400.json` 从原始 RP1 守恒体均值重算
400×400×5 网格，目标 t=0.25，z 周期长度 0.0125，64 MPI、每进程一线程。
启用 `reconstruction.sharedGradientFaceSweep` 后，每个界面根据当时已更新的
梯度计算均值和 θ，将两侧面积分及点值恢复依赖的全部节点梯度同乘 θ。
每次界面事件先去重，同一节点参加后续界面时继续累乘。只遍历一遍，
MPI 按 rank 块顺序同步；不叠加旧侧面 θ，不对 z 导数作特殊修改。
梯度全部更新、同步并重新恢复点值后，才计算物理通量链式导数。

输出目录为 `data/out/NCFV/RP1_shared_gradient_sweep_400_20261026`：
`inputs/` 保存冻结程序、配置和 NCFV 源码，`launch_manifest.json` 记录输入
及程序哈希，`solver.log` 保存迭代日志，`run_status.json` 保存进程号、
物理时间/目标时间、步数及结束状态。VTK 和 restart 每 100 步写出。
旧算例及其 checkpoint 不被覆盖。

独立验证见 `data/out/NCFV/shared_gradient_sweep_runtime/20261026_runtime_probe`。
RP1 与真正三维光滑波各在 np=1/2/4 验证梯度累乘恒等式、owner/ghost
一致性、更新后通量梯度和旧侧面系数恒 1；np1 与独立 Python 重放逐节点
最大差为 0。小网格十步 SSPRK 试算见同级 `20261026_pilot40`。
