# RP1：棱中点 Roe 通量与 Barth 限制器

`run_midpoint_barth.py` 为独立计算构建私有 NCFV 源码副本，不修改生产
C++ 文件，也不覆盖原有结果。几何和重构采用现有
`TraditionalQuadrature` 初始化路径，以保存完整二次多项式系数；私有程序
替换了运行期通量组装，因此配置中的该枚举不代表实际使用面高斯求积。

内部界面的通量为

\[
\Phi_{ij}=|S_{ij}|\,\widehat F_{\rm Roe}
  (P_i(x_{ij}),P_j(x_{ij}),n_{ij}),\qquad
x_{ij}=(x_i+x_j)/2.
\]

每个节点仅使用一个 Barth–Jespersen 系数，缩放二次多项式的全部非均值
系数，保留控制体守恒均值。上下界取本节点及原始棱一环邻居的守恒均值，
分量增量采用参考计算中的绝对 `1e-10` 判零阈值。约束点包括全部相邻棱
中点、本节点点值以及边界微面的重心。额外公共系数保证这些采样状态的
正密度和正压力；不另加压力的局部上下界。每个边界微面在重心计算一次
边界数值通量。内部通量由唯一拥有者计算并共享给相邻控制体，保持守恒。

RP1 沿用 400×400×5 笛卡尔薄层、对偶体精确守恒初值、x/y 透射边界、
z 滑移壁、γ=1.4、SSPRK3、全局 CFL=0.5、最大时间步 `1e-4` 和
非物理 RK 步回退，目标时间 `t=0.25`。重构为 SVD 最小二乘二次重构。

```bash
/home/mrz/.venvs/DNDSR-Kirabo/bin/python \
  cases/ncfv_euler/3D/riemann_barth_400x400x5/run_midpoint_barth.py \
  --output data/out/NCFV/midpoint_barth_RP1_new --ranks 64
```

运行器先检查双进程自由流、单/双进程 RP1 短时一致性和完整时间的小网格
RP1，再启动正式计算。结果目录包含私有源文件、二进制及哈希、运行命令、
原生 H5 检查点、密度/压力/展向速度图、剖面以及展向差异指标。
`status.json` 记录当前运行状态，`validation.json` 记录完成的验证结果。

二维 RP1 的薄层解应沿 z 恒定且展向速度为零。因此沿 z 的非零差异、
展向总变差超过其极差的部分，以及非零展向速度，构成可量化的非物理
扰动证据。密度或压力的全域最大值本身不足以证明数值振荡；应结合
等值线、剖面和上述展向指标判断。

2026-10-26 的有效运行目录为
`data/out/NCFV/midpoint_barth_RP1_20261026_v3/`。
无后缀和 `_v2` 目录保留配置及并行采样检查失败的前置尝试，不作为结果。

## 完整计算结果

有效计算使用 64 个 MPI 进程，3291 步到达 `t=0.25`，求解和最终分析
共约 3694 秒，没有非物理 RK 步回退。最终最小密度为 0.118477，
最小压力为 0.0238481，全部 964,806 个节点的守恒量均有限且密度、压力为正。

| t=0.25 指标 | 原高效积分＋Barth | 二次棱中点＋Barth |
|---|---:|---:|
| 最大密度展向差 | 0.773332 | 1.160733 |
| 最大压力展向差 | 0.615066 | 0.911163 |
| 最大绝对展向速度 | 0.569640 | 0.807598 |
| 密度展向总变差超过极差的最大值 | 0.546668 | 0.637489 |

两组使用同一网格和初值文件（SHA256 核验一致），以及相同物理边界、Roe、
SSPRK3、CFL、最大时间步和终止时间；各自采用其对应的重构、内部及边界
通量近似。前三项应为零，本次中点方案的终态指标分别比原方案大约
50.1%、48.1%、41.8%。终态等值线及密度剖面也出现明显锯齿。
结论是：该棱中点方案加 Barth 后仍存在明显的异常振荡。

前置验证结果：自由流最大守恒量误差 `8.88e-16`；单/双进程短时 RP1
最大守恒量差 `1.43e-11`。`audit_midpoint_barth.cpp` 连接同一私有数值
对象，检查双进程初场的 66,256 个节点点值和棱中点状态，越界数和非物理
状态数均为零。这验证了实际状态限幅，但不意味着完整离散更新具有单调性。

有效结果根目录中的 `validation.json`、`midpoint_bounds_audit.json`、
`input_manifest.json` 和 `build_manifest.json` 保存验证及来源信息；
`comparison.json/png` 保存终态对照；`checkpoint_metrics.json` 和
`oscillation_history.png` 保存演化历史。`RP1_400_np64/diagnostics.png`
包含终态场、剖面和展向误差，原生终态为
`RP1_400_np64/restart_00003291.dnds.h5`。
