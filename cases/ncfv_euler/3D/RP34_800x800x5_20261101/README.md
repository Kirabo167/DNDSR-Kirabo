间断位置为x=y=0.5，γ=1.4。沿用Config3的800×800×5 HEXA8网格，域[0,1]×[0,1]×[0,0.05]，Δz=0.01，z周期、x/y常值外推。初值为精确对偶体交叠体积分数的守恒均值，存于`data/mesh/RP34_800x800x5_initial/`，元数据记录守恒积分、初始正性、网格及CSV哈希。

冻结复用已完成Config3的程序`solver_59cb2a4e98d7e348.exe`及其NCFV源码快照；完整程序SHA256为`59cb2a4e98d7e34830fede9c229f9dff2ebdfc435df47bb7a939fcd9d0ddfe79`。EfficientDifferential、SVDLeastSquares、显式Original模板、SSPRK3、CFL=0.475、最大步长1e-4保持一致。五种策略为SG_BJ_PRES、SG_SIGN_BUDGET、FC_IDP_BINARY、FC_IDP_CONT和LLF_FIRST_ORDER，其中LLF为一阶实际通量对照，程序仍计算未采用的高阶候选。

十组各128 MPI、每进程单线程，最多两组并发。按照RP3/Barth、RP4/Barth、RP3/预算、RP4/预算等顺序交替排队。Linux CPU 0–127和128–255为两个独立物理核槽，不使用其SMT兄弟线程；逐rank亲和性与全局无重叠证据写入结果目录。该绑定不意味着排除其他账户的服务器作业。

启动前使用同一程序逐组运行40×40×5预检至各自终止时间。预检z厚度1.0，以保持Δz/Δx=8；检查时间、独立节点、正密度压力和实际限制参数，记录拒步与展向差异。通过此检查不代表振荡或二维保持误差已消除。

为控制磁盘占用，中间时刻每200步保存完整三维HDF5检查点，VTK仅保存初始、最终场（`outputInterval=1000000`）。检查点包含各节点守恒均值、原始节点编号、物理时间和完整配置，可用于续算、原生z层分析和视频，不依赖中间VTK。没有删除既有结果；启动需要70 GiB可用空间，运行中不足15 GiB时停止本控制器的作业。

输出根目录为`data/out/NCFV/RP34_800x800x5_np128_20261101/`，按`RP3/<方法>/`、`RP4/<方法>/`分别存放。`suite_status.json`键为`RP3/SG_BJ_PRES`等，记录各自目标时间及物理推进比例；`preflight/results.json`为十组预检记录，`physical_affinity_validation.json`为当前两组的核绑定证明。最终检查点通过验证后输出五个真实z层分布、统一色标25等值级比较和CSV指标。
