# RP1：800×800×5，五组限制策略，128 MPI／组，SMT 并发

## 与Kurganov–Tadmor（2002）Configuration 3的比较

四象限初值、γ=1.4、间断位置x=y=0.5与论文Configuration 3一致。文献图3.3（印刷第594页，PDF第11页）取t=0.3、400×400网格点、CFL=0.475；现有五组取t=0.25、800×800×5原始六面体单元、CFL=0.5。不能把两幅物理坐标图直接重叠，或从印刷等值线图计算精确解误差。

`compare_KT2002_RP1.py` 使用ξ=(x−0.5)/t、η=(y−0.5)/t作定性波形归一化，比较左行／下行主激波、中央相互作用区和右上细结构。有限域边界和数值误差不会因归一化消失。论文的等值线数值及原始场未提供，当前结果使用与视频一致的25个全局密度等值级；不宣称与论文逐条等值线一致。图上的大范围细等值线还可能对应接近常值区背景的小幅起伏，不能仅按闭合曲线的面积判断误差。

由截断小数初值的质量跳跃条件，孤立外侧激波速度约−0.663381；t=0.25时参照位置为0.334155，t=0.3时为0.300986。这解释了不同时间的主激波位置差异。z=0.02、y=0.9剖面上，五组激波中点为0.334422、0.334423、0.333772、0.333750、0.333335，均落在参照位置一个网格间距0.00125以内。该位置参照针对外侧一维波段，不是完整二维精确解。

10%–90%密度跳跃宽度依次约2.55、2.55、3.05、2.48、5.68个网格间距。高阶方案较LLF更尖锐，但其最大密度z层差依次为0.297、0.285、0.0370、0.0546；LLF为1.27e-14。中间层密度x/y反射对称误差L∞依次约0.257、0.243、0.107、0.236、5.72e-13。前四组仍存在二维保持性问题，不能仅凭主激波位置接近或图形尖锐就认定已可靠复现论文结果。

论文在Configuration 3评述中明确指出θ=2的过度压缩限制会产生振荡，三阶或θ=1可缓解。当前NCFV限制对象与论文minmod参数化重构不同，这一结论支持“限制形式会影响次级结构”的判断，但不等于验证当前限制器的具体实现。

图像、原始PDF参考副本和量化指标位于输出根目录的`paper_comparison_KT2002_20261030/`：`RP1_vs_KT2002_Fig3p3_similarity.png`、`RP1_outer_shock_profiles.png`、`comparison_summary.json`和`metrics.csv`。后续用户指定的Configuration 13独立算例位于`cases/ncfv_euler/3D/KT2002_Config13_800x800x5/`。

## 五组完成后的视频：25 个等值级（2026-10-30）

`render_five_videos_25contours.py` 读取全部五组已完成的 VTK 时间序列，生成五个密度／压力双栏视频和一个五列两行的合成对比视频。截面 z=0.02；每个变量使用跨五组、跨全程固定的色标和 25 个内部等值级，coolwarm 低蓝高红。等值级超出某帧取值范围时不出线，25 个等值级不等于恰好 25 条连通曲线。

视频覆盖 t=0 至 t=0.25，24 fps，20 秒推进加 1 秒最终停留，共 504 帧。统一物理时间轴采用此前最近的真实保存状态，无时间插值；标题显示真实保存时刻。逐 VTU 分片检查密度、压力有限且为正，随后缓存切片；每个 MP4 完整解码并校验帧数、尺寸和 SHA256。输出目录为 `videos_five_cases_t025_25contours_20261030/`，最终以 `video_status.json` 的 completed 状态为准；输入脚本快照在其 `inputs/` 中。

## 上一阶段：每物理核一个 MPI 进程（2026-10-29）

用户要求停止超线程共享后，原四组作业已全部停止，旧日志与状态保存在输出根目录的 `smt_before_physical_20261029/`。目前改用 `run_suite_physical.py`：最多两组同时运行，每组 128 MPI，分别绑定 Linux CPU 0–127 和 128–255，合计 256 个不同物理核，每个物理核仅一个求解进程。其余算例按原顺序排队接续。OpenMPI 的 `--use-hwthread-cpus` 仅用于明确 PU 编号单位；所选列表排除全部 SMT 兄弟线程，不构成超线程共享。

配置在 `physical_single_thread/`，控制器冻结副本在输出的 `inputs_physical_20261029/`。正负预算、二元回退、连续限制均从核验过的第 100 步检查点（t=0.004425455791895345）恢复；Barth 对照此前尚未保存检查点，从初值重算；LLF 仍从初值开始。检查点读取恢复原始迭代号及物理时间；输出前缀不变，VTK 时间序列保留旧帧并追加新帧。

`physical_restart_plan_20261029.json` 记录恢复文件、哈希、物理时间及正性；`physical_affinity_validation.json` 和各组 `cpu_affinity.json` 记录实际 CPU 亲和性。以下 SMT 说明仅记录本轮首次启动时的历史设置。

本轮仅将上一轮五组的 x、y 网格加密至 800×800，保持最新模板、限制策略及冻结可执行文件。源码中的未提交修改不被修改或重编译。

共同参数：320 万 HEXA_8 单元；计算域 [0,1]×[0,1]×[0,0.05]；Δx=Δy=0.00125，Δz=0.01；z 周期，x、y 四面常值外推；精确对偶体守恒均值 RP1 初值；EfficientDifferential、SVDLeastSquares、SSPRK3、CFL=0.5、最大步长 1e-4，终止 t=0.25。

| 算例 | 方法 | 首轮 Linux CPU |
|---|---|---|
| SG_BJ_PRES | 完整支持共享梯度 Barth＋压力约束 | 0–127 |
| SG_SIGN_BUDGET | 共享梯度正负贡献预算与盒子正性 | 128–255 |
| FC_IDP_BINARY | 完整通量二元回退与比熵下限 | 256–383 |
| FC_IDP_CONT | 完整通量连续限制与比熵下限 | 384–511 |
| LLF_FIRST_ORDER | 一阶 LLF 实际通量，高阶候选仍计算 | 等待首个释放的 CPU 组 |

每组 128 MPI 进程，单进程单线程，组内覆盖 128 个不同物理核。四组同时运行使用 512 个不同逻辑 CPU、256 个物理核；前两组与后两组分别使用同一批物理核的 SMT 兄弟线程。第五组自动接续，避免把 640 个进程绑定到 512 个逻辑 CPU。启动器根据 hwloc 拓扑显式转换 Linux CPU 编号，保存逐 rank 实测亲和性和全局无逻辑核重叠证明。

VTK 每 200 步、检查点每 100 步，并写初始和最终状态。加密后 CFL 步长预计约减半，因此这一保存频率保持接近上一轮的物理时间输出间隔，同时避免磁盘输出量增至八倍。预计本轮文件约 150 GiB；可用空间低于 10 GiB 时控制器停止自身任务，保留已有结果及检查点。没有删除旧结果。

`run_suite_smt.py` 复用上一轮字节一致的可执行文件，核验原小网格验证记录、五组冻结参数及配置检查；运行中记录物理时间、耗时、重试次数；结束以退出码、最终检查点达到 t=0.25、节点身份完整及密度压力有限且为正作为完成依据。之后自动保存真实五层的分布、层差和统一色标比较。完整通量方案仍保留其原有低阶 CFL 条件及边界处理。

输出：`data/out/NCFV/RP1_efficient_limiter_derivation_800x800x5_np128_smt_20261029/`。

用项目环境执行 `run_suite_smt.py`，须从仓库内部启动以便审查路径；脚本自行使用 `build/` 作为求解器工作目录。只启动一次；已有状态文件时拒绝重复启动。SIGTERM 发给控制器会停止其自身创建的 MPI 进程组。

本轮启用 SMT，作业的物理核共享随其他组结束而变化，整体耗时不构成独占同等物理核条件下的严格限制器性能排名。保留日志计时以便按相同并发阶段分析。
