# 单层周期 NCFV 的局部逐分量 Barth P1 限制

本算例在三维六面体网格上推进一个物理层的守恒均值。沿 $z$ 方向平移的几何镜像提供三维重构模板，各镜像的残差按对偶体积加权折回物理层。时间推进采用 SSPRK3，四个侧面采用外推，上下两面周期连接。

## 限制系数作用在哪里

每次重构先检查高阶状态。触发回退的界面两侧都由各自保均值的一次多项式给出棱中点状态，再用 Roe 通量计算界面贡献。对单元 $i$ 的守恒分量 $k$，已有 Barth 上下界给出系数 $\theta_{i,k}$。取 $\theta_{i,s}=\min_k\theta_{i,k}$，按下式混合共享系数与分量系数。

$$
\widehat\theta_{i,k} = (1-\chi_i)\theta_{i,s} + \chi_i\theta_{i,k}.
$$

$\chi_i$ 是三个线性斜坡函数的乘积。各指标在区间下端及以下取 0，在上端及以上取 1。压力和梯度取自限制前的守恒均值及梯度，邻点采用一环模板。

| 指标 | 定义 | 过渡区间 |
|---|---|---|
| 相对压跳 | 邻域压差 $(p_{\max}-p_{\min})/p_{\max}$ | 0.02–0.10 |
| 法向压缩 | 压力梯度单位方向上的速度压缩率，乘该方向的最大邻点投影距离，再除以本地声速 | 0.01–0.06 |
| 压力梯度方向一致性 | 本点及邻点压力梯度在本点压力梯度方向上的正向投影平方和，除以梯度模平方和 | 0.90–0.98 |

对近似平面的压缩激波，$\chi_i$ 可以接近 1。等压接触和膨胀处沿用共享 Barth 系数。限制后的梯度和格点值使用同一个分量系数，记保护密度和压力的公共系数为 $\eta_i$，对偶体质心为 $x_{c,i}$，原梯度为 $g_{i,k}$，则

$$
g^{\mathrm{lim}}_{i,k}=\eta_i\widehat\theta_{i,k}g_{i,k},\qquad
U^{\mathrm{lim}}_{i,k}(x)=\bar U_{i,k}+g^{\mathrm{lim}}_{i,k}\cdot(x-x_{c,i}).
$$

线性增量的体平均为零。在格点和棱中点代入同一表达式即可得到相应的状态。完整通量修正仍对五个守恒分量共用一个系数。传感器复用已交换的均值与原梯度，启用后增加本地压力计算和邻域遍历。

## 编译与复现

使用完整仓库克隆，按项目构建指南准备 `external/` 依赖并激活项目 Python 环境。算例启动器使用单机 Linux、Open MPI 4 的绑核参数及 hwloc 的 `lstopo-no-graphics`。脚本从仓库历史中取出实验算子使用的框架版本 `bee9b412`，在独立构建目录应用 `operator.patch` 并编译。

```bash
case_dir=cases/ncfv_euler/3D/RP1_Barth_single_period_20261123
bash "$case_dir/build.sh"
python "$case_dir/study.py" validate
```

`build.sh` 运行传感器的 C++ 单元测试。`validate` 生成 20×20×1 网格，检查常量保持、MPI 分区、周期镜像数、检查点续算，并对 RP3 的新旧限制器从同一初值推进至 $t=0.3$。在 cs 上用 4 个 MPI 进程、7 个周期镜像和 300 个物理步得到以下结果。

| RP3 新方案的统计量 | 结果 |
|---|---:|
| 局部权重大于零的节点采样 / 节点总采样 | 171,430 / 2,778,300 |
| 逐分量系数实际改变的回退节点采样 | 103,754 |
| 越界的受限界面采样 / 受限界面总采样 | 0 / 5,567,590 |
| 非物理重构状态数 | 0 |
| 最大控制体均值偏差 | $4.44\times 10^{-16}$ |

界面统计覆盖 900 次 RK 阶段及各周期镜像，越界判断容差为 $10^{-10}$。`rp3_comparison.json` 保存新旧方案之间的最大守恒分量差。`result.json` 保存每个算例的正性、均值及通量平衡统计。

`study.py full` 使用 256 个物理核计算 800×800×1 的 RP1，间断交点为 $(0.8,0.8)$，目标为 $t=0.5$。新计算默认启用局部混合，加 `--shared-barth` 可使用共享斜率做对照。`study.py extend --restart <检查点> --until <目标时刻>` 默认继承检查点的限制方式。结果位于 `data/out/NCFV/single_layer_barth/`。
