# NCFV 三维 IV：传统/高效 LS 与 SVDLS 瞬态精度测试

## 测试设置

在四面体、三棱柱、六面体的 IV10/20/40/80 周期网格上，分别运行 `TraditionalQuadrature` 和 `EfficientDifferential` 模式的 `LeastSquares`、`SVDLeastSquares` 重构，共 **48 个独立算例**。全部从同一三维等熵涡初场推进到 **t=1.6**，固定时间步为 0.2、0.1、0.05、0.025，分别对应 8、16、32、64 个 SSPRK3 步。MPI rank 数依次为 1、4、8、16，每 rank 一个 OpenMP 线程。

物理设置：区域 `[0,10]×[0,10]×[0,4]` 三方向平移周期，理想气体 `γ=1.4`，无黏 Euler，Roe 特征通量，限制器关闭。LS/SVDLS 使用相同的约 16 点三维二次模板（`stencilSizeFactor=1.7`）。传统模式为四阶体求积、三阶面求积；高效模式使用预计算微几何差分权重。不额外保留诊断微体几何。

主要精度指标是最终恢复节点密度相对解析等熵涡的对偶体积加权 L2：

\[
E_{\rho,2}(t)=\sqrt{\frac{\sum_i V_i[\rho_i^{\mathrm{recovered}}(t)-\rho_i^{\mathrm{exact}}(t)]^2}{\sum_i V_i}}.
\]

相邻网格的观察阶按 `p=ln(E粗/E细)/ln(h粗/h细)` 计算，其中 `h=(400/N)^(1/3)`，`N` 为周期合并后的唯一节点数。四级网格和时间步**同时**细化，因此下表是本算例的时空联合观察阶，不应解释成单独的空间离散阶数。

## 结论与限制

1. 24 对同网格、同积分模式的 LS/SVDLS 结果在双精度舍入范围内一致；最终密度 L2 的最大绝对差为 **1.39e-17**。当前模板条件下，改用 SVD 伪逆没有带来可见的精度变化。
2. 本次四级网格上，传统模式的最终密度误差均低于对应高效模式。IV80 的高效/传统 L2 误差比为四面体 **1.87**、三棱柱 **1.51**、六面体 **1.77**。该结论只针对这里的等熵涡、参数和固定时间步组合。
3. 三种网格、两种模式的 40→80 观察阶均已进入约 2.5–2.8 区间，其中传统模式分别为 **2.723、2.784、2.845**，高效模式分别为 **2.545、2.709、2.722**。由于时间步与网格同步减半，不能从这些数字分离空间与时间截断误差。
4. 48 项都准确到达 `t=1.6`，最大绝对质量漂移为 **2.91e-11**。报告精度来自求解器恢复节点点值；它不同于对偶控制体均值相对于解析体均值的误差。若需要该均值指标，应另做高阶解析参考积分。
