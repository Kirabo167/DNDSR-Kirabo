# NCFV 三维 IV 网格：传统/高效 × LS/SVDLS/变分重构测试

## 范围与口径

在四面体、三棱柱、六面体的 IV10、IV20、IV40、IV80 周期网格上，完成了 3 × 4 × 2 × 3 = **72 个**算例。每项从同一等熵涡初场推进**一个** SSPRK3 物理步，四级固定步长分别为 0.1、0.05、0.025、0.0125；MPI 进程数分别为 1、4、8、16，每进程一个 OpenMP 线程。网格区域为 `[0,10]×[0,10]×[0,4]`，三方向周期；理想气体 γ=1.4、Roe 通量、无黏、关闭限制器。传统模式用四阶体求积、三阶面求积，高效模式用预计算差分权重；都不额外保留诊断微体几何。

**精度**以相同物理时刻 `t=0` 的恢复节点密度与解析密度的对偶体积加权 L2 误差衡量：

\[
E_{\rho,0}=\sqrt{\frac{\sum_i V_i\,[\rho_i^{\mathrm{recovered}}(0)-\rho_i^{\mathrm{exact}}(0)]^2}{\sum_i V_i}}.
\]

此指标覆盖初场控制体均值离散、重构与点值恢复，不含时间推进误差。每级只推进一个物理步，因而最终时间分别是 `Δt`，**不能**用各级步后误差计算同一时刻的瞬态收敛阶。步后误差仍记录在 CSV 和每项 JSON 中，作为单步行为参考。表中的观察阶使用 `h=(400/N)^(1/3)` 以及 IV40→IV80 的两个 `t=0` 误差计算；它是本组网格的观察值，并不单独证明方法的通用空间阶数。

**时间**分开记录初始化（各 rank 墙钟时间的最大值）和求解器内部的一次 SSPRK3 核心步（各 rank 的最大值）。`march_seconds` 另记录完整 `Run()`，包括初始、最终诊断及逐节点 CSV 写出，不宜作为纯计算加速比。**内存**为各 MPI 进程 `ru_maxrss` 峰值之和，单位 MiB；这是各 rank 高水位之和，不是同一瞬间的整机峰值。各级进程数不同，所以跨级内存和时间同时包含并行规模变化；同级六种算法使用同一进程数。

LS/SVDLS 都用 `stencilSizeFactor=1.7`，即三维默认约 16 点二次模板。变分权重 `w=5`；传统变分用 3 次边中点 sweep，高效变分的界面面均值 PCG 上限为 100 次。**两种变分模式使用不同泛函，不能视作同一个重构仅替换积分实现。**

## 分析

1. **LS 与 SVDLS 精度一致。** 24 对同网格、同模式结果的 `t=0` 误差最大绝对差为 `1.31e-18`；一步后误差也只在舍入位有差异。当前约 16 点模板条件良好，改用 SVD 不能带来可见精度收益。运行时间和 RSS 也接近；细小差异不能在这台共享机器上解释为算法优势。
2. **高效 LS/SVDLS 明显节省推进时间和内存。** IV80 高效 LS 相对传统 LS 的核心单步时间在四面体、三棱柱、六面体上分别约快 13.8、8.1、5.5 倍；峰值 RSS 之和分别减少约 52%、38%、34%。这是同级、同 rank 的比较。高效 LS 的初始误差在 IV80 四面体和六面体上较大，在三棱柱上较小，因此不能把资源收益等同于精度提升。
3. **传统变分在 IV80 三种网格上都给出最低的初始误差**，相比传统 LS 约低 4.5、5.6、5.8 倍；其额外变分 sweep 使核心单步耗时增加。高效变分的精度优势没有跨网格统一方向：IV80 三棱柱优于高效 LS，四面体和六面体则劣于高效 LS；其 PCG 时间也显著高于高效 LS。
4. `t=Δt` 的单步误差与 `t=0` 的排名可以不同，因为时间推进又引入了通量、耗散和时间离散误差。例如 IV80 六面体高效变分的初始误差高于高效 LS，而一步后误差低于高效 LS。评价完整瞬态精度仍需所有级别推进到同一终时刻。

系统为双路 Intel Xeon Gold 6326；运行期间共享机器负载变化明显，个别初始化计时出现与算法复杂度不符的波动。本表是一次实测，不含重复样本或置信区间，适合判断数量级差异，不适合断言 LS 与 SVDLS 之间百分之几的快慢。所有 72 项均完成且最终时刻等于各自 `Δt`；最大单步质量漂移绝对值为 `3.51e-11`。
