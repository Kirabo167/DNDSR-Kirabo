# NCFV 高效通量精度差异：当前变分一次导数版本的诊断与改进路线

## 观察到的差异

相同 IV80 网格、`Δt=0.025`、`t=1.6` 下，最终恢复节点密度的体积加权 L2 为：

| 网格 | 传统变分 + 传统积分 | 变分一次导数 + 高效积分 | 高效 LS + 高效积分 |
| --- | ---: | ---: | ---: |
| 四面体 | 1.579066e-5 | 3.062539e-4 | 6.210724e-4 |
| 三棱柱 | 8.632034e-6 | 1.243711e-4 | 3.203693e-4 |
| 六面体 | 1.521042e-5 | 1.471448e-4 | 3.307885e-4 |

新的高效变分组合相对传统变分仍高约 19.4、14.4、9.7 倍，但比同属高效积分的 LS 更准确。这说明更换重构确实有效，剩余差异应继续在积分与数值通量中定位。三棱柱 IV80 的初始恢复密度误差为 `4.193e-7`，仅为终时刻 `1.244e-4` 的约 0.34%；误差主要在推进期间形成。此前 LS 的固定步长消融显示时间步同步加密对观察阶影响很小，但尚未对**当前变分组合**独立重复该时间消融。

## 高效与传统积分的关键区别

当前 [`NCFVSpatial.cpp`](../../../src/NCFV/NCFVSpatial.cpp) 中，传统路径在对偶微面的每个求积点重构左右状态，按该微面的法向计算 Roe 通量并加权求和。高效路径先计算左右**中心物理通量**的高效积分，再加一个宏面 Roe 修正：

`I_e = (I_phys,L + I_phys,R)/2 + A_e * [Roe(Ubar_L,Ubar_R,nbar) - (F(Ubar_L,nbar)+F(Ubar_R,nbar))/2]`。

这里 `A_e=surface.measure` 是微面标量面积之和，`nbar` 来自微面有向面积向量之和。由于 Roe 耗散对左右状态和法向都非线性，**先合并状态与法向再计算一次 Roe**通常不等于**逐微面计算 Roe 后积分**。这是代码结构给出的机制解释，尚不能仅凭总误差判断“面状态均值误差”“宏面法向合并”及“特征耗散系数”各自占多少。Diskin 与 Thomas 的[节点中心有限体积比较](https://ntrs.nasa.gov/citations/20100003409)也讨论了基于原始边合并通量和逐控制面通量的精度、复杂度权衡；其研究对象是另一类离散格式，不能直接把其阶数结论套到本程序。

## 对当前版本的控制变量试验

诊断探针仅将上述 Roe 修正乘以系数 `α`，保持重构、中心物理通量、时间推进、网格和初值不变。`α=1` 的 IV40 结果与生产基准的 `9.478463517e-4` 相差约 `1e-17`；独立复算 `生产 RHS = 中心 RHS + Roe 修正 RHS` 的最大不符在 IV40/IV80 均小于 `2.2e-13`。

| 三棱柱网格 | 完整 Roe, α=1 | 无 Roe 修正, α=0 | 终时刻误差降幅 | 解析场 t=0 的 ‖Roe RHS‖ / ‖中心 RHS 误差‖ |
| --- | ---: | ---: | ---: | ---: |
| IV40 | 9.478464e-4 | 2.294460e-4 | 75.8% | 10.46 |
| IV80 | 1.243711e-4 | 1.467436e-5 | 88.2% | 9.67 |

IV80 在解析场 `t=1.6` 的瞬时预算中，中心部分密度 RHS 误差为 `1.4595e-5`，Roe 修正范数为 `1.5964e-4`，比值 10.94；只看涡核 `r<3` 也得到约 11.00。因而对**当前变分一次导数 + 高效通量的平滑等熵涡**，宏面 Roe 修正是已验证的主要可移除误差来源。`α=0` 会改变演化轨迹，75.8%/88.2% 是控制变量试验的最终误差降幅，不是每一时刻或每个节点的线性误差分摊。无耗散中心通量缺少间断稳定性，不能直接作为生产替代。

原始诊断结果：[IV40 α=1](iv40_alpha1.json)、[IV40 α=0](iv40_alpha0.json)、[IV80 α=0](iv80_alpha0.json)；[IV80 α=1 生产基准](iv80_alpha1_baseline.json)。探针源码为 [`ncfv_efficient_roe_error_budget_probe.cpp`](../../dev/ncfv_efficient_roe_error_budget_probe.cpp)。

## 改进顺序

1. **先做基准型混合通量。** 保留现有高效中心物理通量积分，只将 Roe 修正改为逐微面或微面求积点计算：每点使用一致的左右重构迹及局部法向，最后仍汇总为每条原始边唯一的一份守恒通量。与当前宏面修正、完整传统积分比较误差和 Roe 求值次数。这最直接检验宏面合并是否造成主要误差，代价是更多局部几何与 Roe 求值。[Nishikawa 与 White 的高阶有限体积工作](https://arxiv.org/abs/2305.01466)也强调高阶精度需要相应的面通量积分；其公式针对单元中心四面体格式，具体权重不能照搬到本节点中心对偶网格。
2. **再研究低成本的高阶修正。** 若逐微面 Roe 明显改进，可对宏面数值通量补曲率/变化项，以少量 Roe 求值近似逐微面积分。上述[Nishikawa–White 论文](https://arxiv.org/abs/2305.01466)给出“单点数值通量 + 曲率修正”的第三阶构造思路；用于本程序时需重新推导非平面宏面、状态变化及法向变化的修正，不能只修中心物理通量。
3. **把平滑区减耗散作为有保护的方案。** `α=0` 可作平滑流诊断；若用于通用求解，应由光滑度/激波指示量控制耗散，间断附近保留稳健上风通量，并检验正性、熵行为与激波稳定性。Yee、Sandham 与 Djomehri 的[特征滤波低耗散研究](https://ntrs.nasa.gov/citations/19980201047)是这种设计方向的实例，但不是可直接套用到当前宏面 Roe 修正的系数公式。
4. **在上述比较后定位剩余项。** 记录每张宏面的左右状态跳跃及分特征波耗散，分离“跳跃来自重构”与“同一跳跃经宏面合并后的积分误差”。同时在严格周期的三维熵波、涡量波和含激波算例上比较收敛、质量守恒、运行时间与内存。仅缩小时间步或把 LS 换成 SVDLS，依据此前同条件消融，预计不能解决当前主要差异；对新变分组合仍应作一次固定网格时间验证。

## 复现

```bash
python3 cases/NCFV/diagnostics/compile_reconstruction_probe.py \
  --source docs/dev/ncfv_efficient_roe_error_budget_probe.cpp \
  --output /tmp/ncfv_roe_budget_var_gradient_20260928
cd build
HWLOC_COMPONENTS=-gl,-cuda,-nvml OMP_NUM_THREADS=1 \
  mpirun --mca pml ob1 --mca btl self,vader -np 16 \
  /tmp/ncfv_roe_budget_var_gradient_20260928 \
  ../cases/NCFV/NCFV_iv80.json /tmp/iv80_alpha0.json \
  Variational 0 0.025 1.6 0
```

最后一个参数是 Roe 修正系数。`Variational 0` 指探针使用当前基准的变分参数：权重 5、邻居迭代 3 次、`stencilSizeFactor=1.7`；探针把运行输出放在结果 JSON 旁边，避免覆盖已有算例。
