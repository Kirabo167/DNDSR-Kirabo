# NCFV 等熵涡加密阶数差异诊断

## 问题与判据

此前四面体、三棱柱、六面体 IV10/20/40/80 的 LS/SVDLS 测试，同时将网格与固定时间步从 `0.2/0.1/0.05/0.025` 加密，统一运行到 `t=1.6`。报告的相邻阶是

\[
p_{i\to j}=\frac{\ln(E_i/E_j)}{\ln(h_i/h_j)},\qquad
h_i=(400/N_i)^{1/3},
\]

其中 `E` 为最终恢复节点密度相对解析等熵涡的对偶体积加权 L2，`N` 为周期商节点数。这是**网格与时间步联合加密的观察阶**，不是固定网格的时间积分阶。LS/SVDLS 在前次 24 对结果中的最终误差最大差仅 `1.39e-17`，因此本诊断只重跑 LS；结论也适用于当前条件下的 SVDLS。

## 1. 直接消融：统一时间步后阶数几乎不变

固定所有四级的时间步为 `0.025`，分别仍计算到 `t=1.6`。IV10、IV20、IV40 重新运行，IV80 复用原测试中本来就为 `0.025` 的结果。网格和 MPI 进程数不变。下表每个三元组依次表示 **10→20、20→40、40→80** 的阶数。

| 网格 | 模式 | 原联合加密阶 | 全部使用 Δt=0.025 后的阶 |
|---|---|---|---|
| 四面体 | 传统 | 1.705 / 2.314 / 2.723 | 1.710 / 2.312 / 2.718 |
| 四面体 | 高效 | 1.288 / 2.224 / 2.545 | 1.290 / 2.223 / 2.542 |
| 三棱柱 | 传统 | 2.004 / 2.402 / 2.784 | 2.005 / 2.401 / 2.777 |
| 三棱柱 | 高效 | 1.755 / 2.359 / 2.709 | 1.758 / 2.357 / 2.705 |
| 六面体 | 传统 | 2.063 / 2.466 / 2.845 | 2.066 / 2.466 / 2.837 |
| 六面体 | 高效 | 1.698 / 2.381 / 2.722 | 1.700 / 2.379 / 2.718 |

18 个阶数的**最大绝对变化为 0.0075**。这个变化远小于同一级别在网格类型和积分模式之间出现的数十分之一的阶数差异。因此，原报告中的主要差异并非“时间步也减半”造成。统一 `Δt=0.025` 仍有有限时间误差，所以上表右列也不能无条件称为纯空间阶；但这个同条件消融足以量化原时间步安排对观察阶的影响。未舍入数字见 [order_decomposition.csv](order_decomposition.csv)。

## 2. 固定网格时间收敛：SSPRK3 在细步长区间呈三阶

在固定 IV10、IV20 上分别使用 `Δt=0.2、0.1、0.05、0.025`，所有解都到 `t=1.6`。不仅比较误差范数，还按相同 `original_node` 比较**整个恢复密度场**，定义

\[
D(\Delta t_a,\Delta t_b)=
\left[\frac{\sum_iV_i(\rho_i^{a}-\rho_i^{b})^2}{\sum_iV_i}\right]^{1/2}.
\]

`D(0.1,0.05)/D(0.05,0.025)` 的二进制对数在 IV10 六组合为 **3.02–3.11**，在 IV20 六组合为 **3.05–3.10**，与三阶 SSPRK3 的细步长行为相符。原加密序列所用步长相对于 `0.025` 参考解的场差，也只占该参考解总误差的：

| 网格 | 模式 | IV10：D(0.2,0.025)/E(0.025) | IV20：D(0.1,0.025)/E(0.025) |
|---|---|---:|---:|
| 四面体 | 传统 | 0.176% | 0.694% |
| 四面体 | 高效 | 0.112% | 0.272% |
| 三棱柱 | 传统 | 0.711% | 1.271% |
| 三棱柱 | 高效 | 0.386% | 0.722% |
| 六面体 | 传统 | 0.617% | 1.332% |
| 六面体 | 高效 | 0.359% | 0.650% |

因此，把原序列中的 IV10/IV20 时间步再减小，对其终时刻解的影响也很小。完整误差、相邻步长场差和时间阶见 [IV10 时间扫描](iv10_temporal_refinement.csv)、[IV20 时间扫描](iv20_temporal_refinement.csv)。

**边界条件提醒：**额外的固定 IV20、六面体高效模式 `Δt=0.2` 不是原加密序列使用的步长。它出现残差 RMS 从约 `0.486` 增至 `2.055`、恢复密度最大值约 `1.088` 的过冲，终时刻误差 `2.55e-2`；减到 `0.1` 后误差约 `1.14e-2`，再细化进入正常三阶时间差分区。这个偏大步长测试说明存在稳定性/非渐近边界，**不能**用它解释原序列 IV20 的阶数，因为原序列该级采用 `0.1`。

## 3. 主差异在空间离散及涡算例的预渐近误差

当前 48 项原测试中，IV80 的初始恢复误差与推进后误差相比如下。初始误差的细端阶显著高于最终误差阶，且初始误差只占最终误差的约 `0.5%–1.7%`：

| 网格 | 模式 | t=0 密度 L2 | t=1.6 密度 L2 | 初始 40→80 阶 | 最终 40→80 阶 |
|---|---|---:|---:|---:|---:|
| 四面体 | 传统 | 2.025e-6 | 3.317e-4 | 3.941 | 2.723 |
| 四面体 | 高效 | 3.270e-6 | 6.211e-4 | 3.786 | 2.545 |
| 三棱柱 | 传统 | 3.645e-6 | 2.117e-4 | 3.150 | 2.784 |
| 三棱柱 | 高效 | 2.674e-6 | 3.204e-4 | 3.498 | 2.709 |
| 六面体 | 传统 | 9.783e-7 | 1.870e-4 | 3.965 | 2.845 |
| 六面体 | 高效 | 1.933e-6 | 3.308e-4 | 3.837 | 2.722 |

这定位了误差出现的**阶段**：主要在解的空间离散演化中积累，而不是 LS 改成 SVD、初始控制体均值投影或最终点值恢复单独造成。当前源码中，[传统模式](../../../src/NCFV/NCFVSpatial.cpp#L594)在每个微面求积点重构左右状态并调用 Roe；[高效模式](../../../src/NCFV/NCFVSpatial.cpp#L654)积分左右物理通量，再对宏面的左右平均状态调用一次 Roe，将修正乘以宏面面积。它们是不同的离散通量，故即使都用同一个 LS 模板，也不应预期相同的误差常数或完全相同的观察阶。不同四面体/三棱柱/六面体网格又给出不同的对偶面形状、法向组合和模板几何。

“IV10/20/40/80”在三种网格里也不是相同的实际节点密度：周期商 IV10 为三棱柱 `512` 节点、四面体/六面体 `1000` 节点；IV80 分别为 `239968` 和 `512000`。本报告用各级实际 `N` 计算 `h`，排除了直接把标签当相同尺寸的阶数计算错误；但绝对误差仍不能仅凭同名 IV 级别作等分辨率比较。

先前的[三棱柱空间误差审计](../ncfv_spatial_accuracy_20260919/report.md)在涡核外侧 `1≤r<2` 环带观察到：界面重构值约 `3.019` 阶，形成离散散度后中心通量残差约 `2.595` 阶、Roe 耗散残差约 `2.641` 阶、总残差约 `2.648` 阶；最终点值恢复不是主导损失。这与本次“时间误差小、演化误差主导”的结果一致。该审计属于先前源码版本，不能代替当前三类网格的完整通量消融；**本轮尚未唯一确定每类网格上是哪一个空间项导致最终的具体阶数**。先前[严格三维光滑波测试](../ncfv_3d_exact_waves_20260920/report.md)在三棱柱传统模式得到接近三阶的结果，也说明等熵涡的低阶观察值不应泛化为所有光滑三维问题的普适阶数。

解析涡使用 [`std::round` 最短周期位移](../../../src/NCFV/NCFVAnalytic.hpp#L23)，远尾周期拼接不是严格全域光滑；这限制了形式阶解释。不过上述历史区域审计发现主要误差在涡核及环带，接缝不是当时的主导贡献。当前三网格上的接缝贡献尚未重新分区量化。

## 4. 独立发现：传统三棱柱 IV20 的模板有分区依赖

原加密序列的 MPI 数为 `1/4/8/16`。将 IV20、`Δt=0.1` 的六种网格/模式 LS 算例从 4 rank 改为 1 rank 后，除传统三棱柱外，最终 L2 相对差都不超过约 `1e-13`。传统三棱柱的 1-rank 结果为 `7.478744546e-3`，4-rank 为 `7.462268009e-3`，相对差 **0.221%**；其差异在 `t=0` 已发生于同一 xy 位置 `(6.968911...,5.25...)` 的 8 个 z 向节点。两次运行的这些节点控制体均值和体积分别一致到约 `1e-14`、`1e-15`，但恢复点值最大差 `7.90e-5`。

针对这 8 个节点的重构算子探针确认：两个分区方式的直接邻居数都为 `8`、最终模板都为 `16` 点，然而每个节点有 **4 个选入的二环位移点不同**，逆算子和条件数也随之改变。因此分区依赖至少发生在当前传统三棱柱的紧致模板选点阶段；本轮还未把其根因进一步区分为候选 halo 输入、几何打分近并列或最终择优规则。它对本次相邻观察阶的影响约 `0.0033`，远小于前述约 `0.2–0.8` 的方法/网格差异，**不能解释主要现象**。六组合原始对照见 [partition_comparison.csv](partition_comparison.csv)；探针源码见 [`compare_partition_stencils.cpp`](../../../cases/NCFV/diagnostics/compare_partition_stencils.cpp)。

## 结论

1. **时间加密不是主要原因。** 在同一 `Δt=0.025` 下重新计算全部三段阶数，最大改变量仅 `0.0075`；固定网格解场差分在细步长区间约三阶。
2. **观察阶不同主要反映不同空间算子与网格的预渐近误差。** 初始恢复误差小且收敛更快，误差在通量与离散散度推进中形成；传统与高效模式本身使用不同面通量近似。当前证据定位了阶段和可能机制，但没有给出三种网格各空间误差项的唯一分摊。
3. **传统三棱柱 IV20 另有小幅 MPI 分区依赖。** 它来自 8 个节点的模板选点差异，值得单独修复和回归测试，但不足以解释本次阶数的主体差异。
