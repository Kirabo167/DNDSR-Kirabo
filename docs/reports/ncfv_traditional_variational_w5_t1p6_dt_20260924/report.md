# NCFV 传统变分重构：推进至 t=1.6 的精度测试

## 测试设置

- 三维周期等熵涡，四面体、三棱柱、六面体网格，各取 IV10、IV20、IV40、IV80。
- 传统积分模式 `TraditionalQuadrature`，变分重构权重 5，迭代 3 次；体积分阶数 4、面积分阶数 3，不使用限制器。
- Roe 数值通量，固定时间步长的 SSPRK3；四级网格依次使用 Δt = 0.2、0.1、0.05、0.025，均推进至 t=1.6，对应 8、16、32、64 步。
- 表中误差为最终时刻恢复的节点密度点值相对解析解的体积加权 L2 误差：`sqrt(sum(V_i * (rho_i - rho_exact,i)^2) / sum(V_i))`。
- 相邻两级的观测阶为 `ln(E_coarse/E_fine) / ln(h_coarse/h_fine)`，其中 `h=(400/N_nodes)^(1/3)`。三棱柱各级节点数不严格按 8 倍增长，故用实际 `h` 比值。

## 逐级观测精度阶数

| 网格 | IV10 → IV20 | IV20 → IV40 | IV40 → IV80 |
| --- | ---: | ---: | ---: |
| 四面体 | 2.665 | 3.652 | 4.466 |
| 三棱柱 | 2.583 | 4.166 | 4.228 |
| 六面体 | 2.504 | 4.387 | 3.270 |

四面体与三棱柱在最后一级分别得到约 4.47 和 4.23 阶；六面体最后一级降至约 3.27 阶。这里网格尺度和时间步长同步变化，所列数值是该等熵涡算例的**联合加密观测阶**，不能单独解释为重构的空间阶或 SSPRK3 的时间阶。要分离两种误差，须在同一网格上独立加密时间步长，或在时间误差足够小的条件下单独加密网格。
