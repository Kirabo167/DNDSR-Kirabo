# NCFV 传统积分 + LS：Roe 修正开关精度对照

## 测试设置

三维周期等熵涡，四面体、三棱柱、六面体 IV10/20/40/80 网格；固定时间步 `0.2/0.1/0.05/0.025`，SSPRK3 推进到 `t=1.6`。MPI 进程数依次为 `1/4/8/16`。两组均使用 `TraditionalQuadrature + LeastSquares`、权重相同的二次 LS 模板、四阶体求积、三阶面求积、无限制器和无黏 Euler。

每个微面求积点的传统 Roe 通量分解为

`F_Roe(U_L,U_R,n) = [F(U_L,n)+F(U_R,n)]/2 + D_Roe(U_L,U_R,n)`。

完整 Roe 取 `α=1`，诊断的关闭修正取 `α=0`，计算通量为 `F_center + α D_Roe`。两组重构、中心通量求积、网格、时间步和初始条件保持一致。每条原始边的全部微面贡献仍汇总为一份守恒边通量。

完整 Roe 的 12 个基线结果取自[传统 LS/SVDLS 测试](../ncfv_ls_svdls_t1p6_dt_20260924/report.md)。[IV10 三棱柱的 α=1 诊断复算](prism_iv10_alpha1_validation.json)与该基线的最终密度 L2 相差 `1.04e-17`，初始 RHS 的中心/Roe 拆分最大不符为 `3.66e-15`。因此后续 α=0 结果使用同一诊断程序与已核对的基线逐项比较。

## 结果分析与校验

1. 在这个光滑周期涡中，关闭 Roe 修正对四面体、六面体的细网格误差有明显改善，但对三棱柱 IV80 的误差增加了 71.8%。所以不能把“关闭 Roe”视为跨网格类型的通用精度改进。
2. 初始解析场的离散 RHS 预算为这种差异提供线索：IV80 四面体、六面体的中心通量误差范数分别为 `3.48e-5`、`2.72e-5`，Roe 修正项范数分别为 `6.36e-4`、`2.16e-4`；三棱柱的中心误差和 Roe 项分别为 `2.90e-4`、`3.12e-4`，处在同一量级。这表明 Roe 项在四面体和六面体细网格上的截断误差贡献较大；三棱柱的剩余中心通量误差也不可忽略。瞬时 RHS 预算并不能单独证明全时段误差的因果分解。
3. 所有 12 个关闭修正算例均到达 `t=1.6`。最大绝对质量漂移为 `3.14e-11`；初始 `RHS_full = RHS_center + RHS_Roe` 的最大残差为 `4.51e-14`。关闭 Roe 仅用于本光滑流精度诊断；本测试没有覆盖激波和间断流动的稳定性。

完整数值及两组逐级观察阶见[指标 CSV](metrics.csv)；每个 `*_alpha0.json` 保存误差、质量漂移和初始/终态解析场的 RHS 拆分预算，对应日志保留运行输出。
