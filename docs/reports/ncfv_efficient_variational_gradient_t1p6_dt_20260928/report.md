# NCFV 变分重构一次导数 + 高效通量积分：t=1.6 精度测试

## 实现与测试条件

变分重构继续使用边中点的值、一阶导数和 Hessian 跳跃泛函，以完整二次最小二乘系数为初值迭代。本组合在变分迭代结束后，从二次系数的一次项除以对应的方向参考长度，取得节点物理梯度。高效微分积分用这些梯度恢复节点点值、形成界面状态和物理通量积分；通量积分不读取二次系数或 Hessian。本组合不使用已经移除的界面面均值变分泛函及 PCG。

- 三维周期等熵涡；四面体、三棱柱、六面体网格各取 IV10、IV20、IV40、IV80。
- `EfficientDifferential + Variational`；变分权重 5、邻居迭代 3 次；Roe 通量，不使用限制器；固定时间步 SSPRK3。
- IV10/20/40/80 的时间步长依次为 0.2/0.1/0.05/0.025，分别推进 8/16/32/64 步，最终时间均为 1.6。MPI 进程数依次为 1/4/8/16。
- 误差 (E_2) 是最终时刻恢复的节点密度点值相对解析解的体积加权 L2 误差：`sqrt(sum_i(V_i*(rho_i-rho_exact,i)^2)/sum_i(V_i))`。
- 逐级观测阶 (p=\ln(E_{2,c}/E_{2,f})/\ln(h_c/h_f))，(h=(400/N_{node})^{1/3})。三棱柱网格的节点数并非严格八倍增长，故使用实际 (h) 比值。

同样的网格与时间步下，本组合的最终误差低于高效 LS，但高于传统变分。两种积分模式对初始涡的对偶体均值和节点点值恢复也采用各自的积分规则，因此这张表比较的是**完整算法组合**的误差，不能把误差差额全部归因于通量公式。
