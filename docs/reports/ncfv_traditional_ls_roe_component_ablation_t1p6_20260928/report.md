# NCFV 传统积分 + LS：Roe 修正逐守恒分量消融

## 测试定义

将界面 Roe 通量写为中心物理通量与修正项之和：

`F_Roe = (F_L + F_R)/2 + D_Roe`。

这里的“分量”指三维 Euler **守恒通量向量**的五个条目：质量 `ρ`、x/y/z 动量 `m_x/m_y/m_z` 和总能量 `E`；它们不是 Roe 的五个特征波。每次仅将 `D_Roe` 的一个条目乘以 0，其余四个条目保持 1。完整 Roe 作为同条件基线。该开关仅用于内面通量；本测试采用三方向周期边界。

算例为三维周期等熵涡，使用 `TraditionalQuadrature + LeastSquares`、二次 LS 重构、无限制器、无黏 Euler、SSPRK3。四面体、三棱柱、六面体使用 IV10/20/40/80；时间步依次为 `0.2/0.1/0.05/0.025`，推进到 `t=1.6`，MPI 进程数依次为 `1/4/8/16`。主指标为恢复节点密度相对解析解的对偶体积加权 L2；另外检查压力 L2 和质量漂移。各网格、各级别的完整 Roe 与五种单分量消融共 72 组。

## 实现校验

诊断程序在初始场独立计算完整 Roe RHS、中心通量 RHS 和 Roe 修正 RHS。每种单分量消融的 RHS 再与“完整 RHS 减去该分量修正”逐节点核对。新接口五分量全部关闭时，三棱柱 IV10 的密度 L2 为 `0.030198932244556036`，与[上一轮独立中心通量实现](../ncfv_traditional_ls_roe_ablation_t1p6_20260928/report.md)相差 `1.39e-17`；对应初始 RHS 最大差为 `2.94e-15`。

细网格后续算例使用仅输出终态点值误差的精简诊断，省去不参与本比较的高阶解析均值和终态静态预算；固定时间步下也不重复计算局部时间步与残差范数。三棱柱 IV10 总能量消融的完整诊断、精简诊断及固定步长优化诊断给出的密度 L2、压力 L2 和质量漂移在双精度舍入内一致。

## 解释与校验

1. 对本测试的**密度精度**，IV80 四面体和六面体受总能量修正影响最大，关闭后误差分别增加至 `4.40`、`7.62` 倍；三棱柱则由 y 动量主导，达到 `10.13` 倍，同时 x 动量组无法稳定到达终点。故不存在跨三种网格的单一最严重分量。
2. 对**压力精度**，四面体 IV80 受质量分量影响最大（`1.74` 倍），三棱柱受 y 动量影响最大（`9.91` 倍），六面体受总能量影响最大（`4.40` 倍）。三棱柱 y 动量和六面体总能量的 40→80 密度观察阶分别降为 `1.083` 和 `1.494`，而各自完整 Roe 为 `2.784` 和 `2.845`。
3. 三棱柱 IV80 x 动量算例在推进中出现非物理锚点压力 `p=-0.1163` 并退出；该组没有最终误差，见[失败状态](failed_cases_all.csv)及 `prism_iv80_mx.log`。关闭 z 动量修正在三棱柱和六面体 IV80 上的密度 L2 变化分别约 `-7.46e-12`、`-3.09e-18`；四面体变化为 `+0.0024%`。本涡流沿 z 方向均匀，不能据此推断一般三维流动中该分量无作用。
4. [上一轮五分量全部关闭测试](../ncfv_traditional_ls_roe_ablation_t1p6_20260928/report.md)中，四面体、六面体 IV80 的密度误差反而降低。该现象与这里各单分量关闭多数增大误差同时成立，说明最终 L2 误差不能由单分量效应线性相加；分量间的耦合与误差抵消是合理解释，但本消融实验本身不能唯一确定机制。

12 个完整 Roe 密度基线与上一轮同条件结果的最大绝对差为 `3.43e-17`。71 个成功算例均到达 `t=1.6`；最大绝对质量漂移为 `3.52e-11`，初始逐分量 RHS 校验最大残差为 `6.25e-14`。完整成功数据见[总指标 CSV](metrics_all.csv)，失败原因见[失败状态 CSV](failed_cases_all.csv)，每组 `*.json` 和日志保留原始输出。NCFV 的 7 项 C++ 单元测试全部通过。
