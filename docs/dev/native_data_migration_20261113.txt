DNDSR-Kirabo native data structure migration (2026-11-13)

Baseline: local cf046596251c2c44318ee5d069b5d029e5dd58f2, including the user's
existing Geom/NCFV changes. Reference: harryzhou2000/DNDSR at
611b0a0b7a6b3ac9a54be891919f9016a8756471. This imports the reference version's
data infrastructure, rather than applying that individual commit's Cauchy diff.

Implemented
1. Runtime Buffer/Allocation, immutable RowLayout/metadata, Array and RowBuilder,
   typed views, allocation diagnostics, explicit reads/writes and generations.
2. RowTransferPlan/PayloadPlan/TransferBinding, element schemas, transient and
   persistent transfers, controller-driven MPI progress and eager CPU/CUDA streams.
3. DofSpace, DofField, DofBundle, component views, native algebra, halo and scratch.
4. Existing host_device_vector/Array host allocations now use that same Buffer.
   Legacy value copies remain deep copies. Retained allocation/row owners survive
   resizing or destruction; uncompressed CSR rows detach before structural edits.
5. ShareLegacyHost and ShareLegacyDofField explicitly share existing values without
   copying/reordering them. Geom element and periodic-bit POD schemas preserve
   their current physical layout and can be registered before MPI initialization.
6. The local include tree, ArrayPair/ArrayDof APIs, existing solver equations,
   sparse NodeHalo topology, configuration and legacy checkpoint formats remain.
   OptionalRef retains its legacy spellings and gains checked/const-safe borrows.

Required usage
- Retain a single DofSpace descriptor for fields using the same prepared row order.
  Equal dimensions alone do not imply compatible row identities.
- Runtime copies alias. Clone explicitly copies values. Legacy copies still copy
  values. ShareLegacyHost publishes a retained layout snapshot, not a live mirror.
- Read()/Write() scopes or declared eager operands protect native accesses. Finish
  them before legacy raw arithmetic or legacy ArrayTransformer MPI operations.
  Raw legacy writes do not automatically advance native value generations.
- Recreate field/layout-dependent bindings after replacing or redistributing legacy
  arrays. An old alias safely retains the old allocation; it does not follow Resize.
- Legacy device mirrors retain explicit to_host/to_device coherence. Native host
  sharing requires no independent legacy device mirror. Native CUDA uses explicit
  placement/copy and completion. No implicit cross-stream dependencies are inserted.
- Matrix-valued legacy DOF rows retain their flat component order in the bridge.
  The bridge performs no transpose, component remapping, or mean/point conversion.

Scope boundary
The following boundary records the first storage-layer stage. The subsequent
native mesh/Cauchy migration supersedes its exclusions of Runtime Python,
ArrayIO, native mesh and Cauchy; see native_framework_migration_20261113.txt.
This is a compatible update of the common storage, communication and DOF layer.
The Geom facade still uses the local tracked legacy mesh representation, and
Euler/ACM/NCFV still own their established field types and outer execution loops.
The reference's native mesh/entity registry and Cauchy EquationDofs/solver have
not replaced those modules. New Runtime Python bindings, native ArrayIO archives,
AmgX and an NCCL build dependency are not enabled by this change. The native NCCL
provider remains unavailable unless its compile-time backend is explicitly built.
