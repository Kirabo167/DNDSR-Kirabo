# LS 13 点模板高效 NCFV 三棱柱网格精度测试（2026-09-24）

## 测试设置

- 三棱柱等熵涡网格：IV10、IV20、IV40、IV80。
- 重构：二次最小二乘（`LeastSquares`），高效积分（`EfficientDifferential`）。
- 目标模板数为 13；运行日志确认四级网格的实际模板统计均为
  `stencil[min,mean,max]=[13,13,13]`。
- 标准 Roe 通量及程序内熵修正；关闭限制器和黏性项。
- 固定全局时间步分别为 0.2、0.1、0.05、0.025；推进到 \(t=1.6\)，
  对应 8、16、32、64 步，不使用局部时间步。
- MPI 进程数分别为 1、4、8、32。
- 控制体均值的解析参考由每个微四面体 24 点规则计算；误差按节点对偶
  控制体积加权。相邻阶数采用
  \(h=(400/N_{\mathrm{node}})^{1/3}\)。

## 结论

1. LS 13 点高效格式的误差随网格加密稳定下降，密度均值 L2 的观测阶从
   1.70 提高到 2.32，再到 2.74；恢复格点密度的最后一级为 2.76。
2. 40→80 已接近三阶，但在这四级等熵涡测试中尚不能判定达到渐近三阶。
   Roe 耗散、周期拼接误差和时间误差仍共同存在。
3. 模板缩至 13 点后条件数最大值依次为 3.72、4.80、5.38、5.35，未出现
   病态矩阵；所有计算均完成到 \(t=1.6\)，没有非物理状态。
4. 80 网格首次使用 32 MPI 进程时触发了求解器自带节点诊断输出的目录创建
   竞争。复算时只将诊断目录提前创建并隔离，数值格式和参数未改变；最终运行
   使用 32 进程，未超过 64 核。

诊断程序为 `docs/dev/ncfv_refined_prism_accuracy_probe.cpp`。本轮未修改生产
求解器的数值通量、重构或时间推进实现。
