# NCFV 高效算法中 Roe 耗散项的微分展开可行性（2026-09-22）

## 结论

可以把 Roe 耗散当作左右界面重构状态和法向的非线性函数，沿用高效算法的微面微分权重积分。但当前实现已经**精确积分了冻结 Roe 算子乘以状态跳跃**的部分。真正需要新增的是 Roe 算子随面内状态、熵修正分支及微面法向的变化；只展开跳跃量不会改变现有公式。

若要求一般情况下与逐微面积分 Roe 通量相同，就不能同时只保存左右宏面平均状态、只做每条原始边一次 Roe 求值。微分展开可以构造无 Gauss 点的高阶近似，但其精度、稳定性和耗时须与传统求积路径作独立比较。

以下从 NCFV 当前使用的**常 γ、单组分理想气体 Euler 方程**推导。可变 γ、组分基准能和被动标量需要重新检查波强度及其导数，不能直接套用这里的简式。

## 从 Euler 通量到 Roe 耗散

### 1. 守恒变量与法向物理通量

令 U = (ρ, m, 𝓔)，其中 m = ρu，𝓔 = ρE。压力、总焓和单位法向 n 上的速度分别为

p = (γ − 1)[𝓔 − |m|²/(2ρ)]，　H = (𝓔 + p)/ρ，　q = u·n。

Euler 法向通量是

Fₙ(U) = (m·n, mq + pn, (𝓔 + p)q)。

Roe 数值通量把两侧物理通量的算术平均与特征耗散组合：

Fᴿᵒᵉ(U_L, U_R, n) = ½[Fₙ(U_L) + Fₙ(U_R)] − ½D(U_L, U_R, n)。

下文推导的 D 是**未乘 ½ 的耗散向量**。面积积分中也只在最后乘一次 ½。

### 2. Roe 平均及其割线性质

令 s_L = √ρ_L、s_R = √ρ_R、s = s_L + s_R，并以波浪号表示 Roe 平均：

ũ = (s_L u_L + s_R u_R)/s，　H̃ = (s_L H_L + s_R H_R)/s，　ρ̃ = s_L s_R。

ã² = (γ − 1)(H̃ − ½|ũ|²)，　q̃ = ũ·n。

这种权重给出关键的二次项割线恒等式：

Δ(|m|²/ρ) = 2ũ·Δm − |ũ|²Δρ，　其中 Δf = f_R − f_L。

因此压力跳跃满足

Δp = (γ − 1)[Δ𝓔 − ũ·Δm + ½|ũ|²Δρ]。

为把割线性质核对到每个守恒分量，先在任意状态 U 上对通量施加增量 δU = (δρ, δm, δ𝓔)。记 δp = (γ − 1)[δ𝓔 − u·δm + ½|u|²δρ]，则 Jacobian 的作用为

Aₙ(U)δU = (n·δm,

　　　　　　qδm + u(n·δm − qδρ) + δp n,

　　　　　　q(δ𝓔 + δp) + H(n·δm − qδρ))。

取 U 为 Roe 状态、δU 为 ΔU。上式的 δp 恰等于实际 Δp；√ρ 加权还给出两个乘积的割线恒等式：

Δ(mq) = q̃Δm + ũ(n·Δm − q̃Δρ)，

Δ(ρHq) = q̃Δ(ρH) + H̃(n·Δm − q̃Δρ)。

因为 ρH = 𝓔 + p，三个通量分量逐一与该 Jacobian 的作用相等，得到 Roe 割线性质

Fₙ(U_R) − Fₙ(U_L) = Ãₙ ΔU。

这里 Ãₙ 是以 ũ、H̃ 和法向 n 形成的 Euler 法向 Jacobian。熵修正只修改下文耗散所用的**绝对特征值**，不改变这条未取绝对值的割线关系。

### 3. 从特征波重构状态跳跃

Ãₙ 的声学特征速度是 q̃ − ã、q̃ + ã；接触波与切向波的速度都是 q̃。相应的两个声学右特征向量及一个接触右特征向量为

r₋ = (1, ũ − ãn, H̃ − ãq̃)，

r₊ = (1, ũ + ãn, H̃ + ãq̃)，

r₀ = (1, ũ, ½|ũ|²)。

无须显式选择切向基。定义动量相对于 Roe 速度的跳跃及其法向、切向部分：

j = Δm − ũΔρ，　jₙ = n·j，　jₜ = j − jₙn。

再定义 θ = Δp/ã²、z = jₙ/ã。声学波强度与接触波强度为

α₋ = ½(θ − z)，　α₊ = ½(θ + z)，　α₀ = Δρ − θ。

切向波的合向量为 T = (0, jₜ, ũ·jₜ)。于是

ΔU = α₋r₋ + α₀r₀ + T + α₊r₊。

可逐分量核对：密度分量为 α₋ + α₀ + α₊ = Δρ；法向动量的附加量为 ã(α₊ − α₋) = jₙ；切向动量由 T 补齐。能量分量利用 ã² = (γ − 1)(H̃ − ½|ũ|²) 和上面的 Δp 恒等式，恰为 Δ𝓔。这也说明波强度不是随意选取的，而是解右特征向量重构 ΔU 得到的。

### 4. Roe 耗散的完整表达式

记熵修正后的非负特征值为 λ₋、λ₀、λ₊。Roe 耗散为

D = λ₋α₋r₋ + λ₀(α₀r₀ + T) + λ₊α₊r₊。

利用上一节的 ΔU 重构式，消去接触与切向波，可得更适合微分展开的等价式：

D = λ₀ΔU + (λ₋ − λ₀)α₋r₋ + (λ₊ − λ₀)α₊r₊。

它把完整耗散写成一个标量跳跃项及两个声学修正项，计算中不必建立完整的特征向量矩阵。在未作熵修正的位置，λ₋ = |q̃ − ã|、λ₀ = |q̃|、λ₊ = |q̃ + ã|。项目的 `Roe` 路径还通过 `Roe_EntropyFixer<0>` 对这三组数值作 Harten–Yee H2 修正。

## 当前代码对应的数学式

设原始边对应的对偶宏面为 Γₑ，各微面的面积和法向分别为 Sₖ、nₖ。宏面的几何量是：

- 标量面积：Sₑ = Σₖ Sₖ。
- 合面积向量：Aₑ = Σₖ Sₖ nₖ。
- 宏面法向：nₑ = Aₑ / ‖Aₑ‖。

当前高效路径按微面法向积分左右中心物理通量，但 Roe 耗散使用左右宏面平均状态 Ū_L、Ū_R 和宏面法向 nₑ：

Φ̂ₑ = ½(Iᶠ_L + Iᶠ_R) − ½Sₑ Bₑ(Ū_R − Ū_L)，其中 Bₑ = |Ã(Ū_L, Ū_R, nₑ)|。

这里 B = R|Λ|L，特征值包含所选的熵修正。代码通过一次数值通量减去同一对平均状态的中心物理通量，取得该耗散修正：

- [`NCFVSpatial.cpp`](../../src/NCFV/NCFVSpatial.cpp) 中的 `EfficientIntegratedPhysicalFlux`、`EfficientSurfaceMean` 和 `EvaluateOwnedEdgeFlux`；
- [`Gas.hpp`](../../src/Euler/Gas.hpp) 中的 `ComputeRoePreamble`、`Roe_EntropyFixer` 和 `RoeFlux_IdealGas_HartenYee`；
- [`NCFVDualGeometry.cpp`](../../src/NCFV/NCFVDualGeometry.cpp) 中的 `AddEdgeSurfaceSimplex`。

这里的 Roe 平均不是两侧 Jacobian 的算术平均。速度和总焓等量用 √ρ 加权，由此构造 Roe 特征系统；而调用它的左右输入是两侧的**宏面平均状态**。

## 冻结算子与完整耗散的差别

令 ΔU(x) = U_R(x) − U_L(x)。如果在宏面上冻结 Bₑ，则

∫(Γₑ) Bₑ ΔU(x) dS = Bₑ ∫(Γₑ) ΔU(x) dS = Sₑ Bₑ(Ū_R − Ū_L)。

这正是当前计算。它对冻结后的线性项没有遗漏任何面内状态变化。

上面的积分恒等式以 Ū_L、Ū_R 是相应左右迹的面积平均为前提。代码用微分权重近似这些均值，必要时还通过 `PreservePhysical` 调整；因此“冻结后精确”指**相对于已得到的宏面数值均值**的线性代数关系，不意味着整个数值均值本身没有求积误差。

完整的逐点 Roe 耗散为

I_D = ∫(Γₑ) B(U_L(x), U_R(x), n(x)) ΔU(x) dS。

因此有精确恒等式

I_D = Sₑ Bₑ ΔŪ + ∫(Γₑ) [B(x) − Bₑ] ΔU(x) dS，

其中 ΔŪ = Ū_R − Ū_L。积分项才是要展开的对象。即使固定法向，B 对状态也是非线性的。例如标量 Burgers 方程在 Roe 速度为正的区间内，耗散为 D = (u_L + u_R)(u_R − u_L)/2。对 u_L = 1 + x、u_R = 2 + 2x、x ∈ [−½, ½]，面积平均耗散为 13/8，而由左右面积平均状态得到的耗散为 3/2。

若以左右面积平均状态作展开基点并保持法向不变，一阶状态偏差的面积平均为零。只把 B 作一次线性修正再乘以**平均跳跃**，因此没有贡献。首个非零修正通常来自 B 的面内变化与跳跃变化的相关项，以及 B 的二阶状态变化。这解释了为什么简单增加一个 Bₑ∇ΔU 项不能改善当前积分。

## 对整个耗散向量求空间导数

现在固定一片微面的单位法向 n，并选择一个空间坐标 xⱼ。下文的撇号表示对 xⱼ 求导；每个 j 重复计算一次，即得到 ∇D。左右的 U、U′ 应来自这条边**各自的界面迹重构**，不是把同一个全局节点值同时当作左右迹。

### 1. 左右状态的热力学导数

对 i = L、R，已知重构给出的 ρᵢ′、mᵢ′、𝓔ᵢ′ 后，先计算

uᵢ′ = (mᵢ′ − uᵢρᵢ′)/ρᵢ，

pᵢ′ = (γ − 1)[𝓔ᵢ′ − uᵢ·mᵢ′ + ½|uᵢ|²ρᵢ′]，

Hᵢ′ = (𝓔ᵢ′ + pᵢ′ − Hᵢρᵢ′)/ρᵢ。

这里 γ 固定，因此没有 γ′ 项。为避免对熵修正的侧声速重新推导，也可由 aᵢ² = γpᵢ/ρᵢ 得到

aᵢ′ = γ[pᵢ′/ρᵢ − pᵢρᵢ′/ρᵢ²]/(2aᵢ)。

### 2. Roe 平均的导数

sᵢ′ = ρᵢ′/(2sᵢ)。对任意按 √ρ 加权的量 f̃，例如 ũ 的每个分量或 H̃，有

f̃′ = [s_L f_L′ + s_R f_R′ + s_L′(f_L − f̃) + s_R′(f_R − f̃)]/s。

据此得到 ũ′ 和 H̃′，再计算

ã′ = (γ − 1)(H̃′ − ũ·ũ′)/(2ã)，　q̃′ = ũ′·n。

同一微面内部 n 恒定，所以没有 n′ 项；相邻微面的不同法向在**逐微面求和**时处理。若直接把不共面宏面当成光滑面并对 n 求导，须另建几何法向模型，不能从现有压缩权重中自动得到。

### 3. 波强度和特征向量的导数

跳跃导数及辅助量为

Δρ′ = ρ_R′ − ρ_L′，　Δm′ = m_R′ − m_L′，　Δp′ = p_R′ − p_L′，

j′ = Δm′ − ũ′Δρ − ũΔρ′，　jₙ′ = n·j′。

因此

θ′ = Δp′/ã² − 2Δp ã′/ã³，

z′ = jₙ′/ã − jₙã′/ã²，

α₋′ = ½(θ′ − z′)，　α₊′ = ½(θ′ + z′)。

声学右特征向量的导数是

r₋′ = (0, ũ′ − ã′n, H̃′ − ã′q̃ − ãq̃′)，

r₊′ = (0, ũ′ + ã′n, H̃′ + ã′q̃ + ãq̃′)。

由于采用了上一节的紧凑耗散式，不必单独求 α₀′、切向基导数或 T′。

### 4. 熵修正特征值的导数

先看没有熵修正且特征速度不为零的分支。令带符号的特征速度 b₋ = q̃ − ã、b₀ = q̃、b₊ = q̃ + ã。对任一波族 σ ∈ {−, 0, +}，有

λ[σ] = |b[σ]|，　λ[σ]′ = sign(b[σ])b[σ]′。

实际 `Roe` 路径的 Harten–Yee H2 修正还依赖两侧同一波族的带符号特征速度 b[σ,L] 和 b[σ,R]。例如 b[−,L] = u_L·n − a_L，b[+,R] = u_R·n + a_R。令 c 为代码中的熵修正尺度；NCFV 的 `Roe` 调用中 c = 0.05。定义

t[σ] = c·max(0, b[σ] − b[σ,L], b[σ,R] − b[σ])，　w[σ] = |b[σ]|。

当 w[σ] ≥ t[σ] 时，λ[σ] = w[σ]；当 w[σ] < t[σ] 时，λ[σ] = ½(w[σ]²/t[σ] + t[σ])。在后一分支内求导得到

λ[σ]′ = (w[σ]/t[σ])w[σ]′ + ½[1 − (w[σ]/t[σ])²]t[σ]′。

t[σ]′ 由 `max` 当前选中的分支求出，b[σ,L]′、b[σ,R]′ 则使用左右速度及侧声速的导数。阈值为正时 H2 可以平滑绝对值在零点的尖角；但 `max` 活动项切换或阈值同时降为零的位置仍可能没有经典导数，不能在这些位置假定单一 Taylor 多项式有效。

### 5. 整个 Roe 耗散的导数

对紧凑式 D = λ₀ΔU + (λ₋ − λ₀)α₋r₋ + (λ₊ − λ₀)α₊r₊ 逐项使用乘积法则：

D′ = λ₀′ΔU + λ₀ΔU′

　　+ Σ(σ = −, +)[(λ[σ]′ − λ₀′)α[σ]r[σ]

　　　　　　　　+ (λ[σ] − λ₀)(α[σ]′r[σ] + α[σ]r[σ]′)]。

这就是“整个耗散项展开”必须包含的项。仅保留 λ₀ΔU′，或把所有 λ、α、r 冻结后只求 ΔU′，又退化为冻结矩阵乘跳跃的计算，不能恢复非线性变化。

## 从耗散导数到高效微面积分

对宏面中的微面 K，固定其法向 nₖ，并把刚才推得的 D 视为该微面上的向量函数 Dₖ(x)。令微面有 N 个构造顶点 rᵣ，选展开点 xᵢ，记 dᵣ = rᵣ − xᵢ、dΣ = Σᵣ dᵣ、微面标量面积为 S_K。

对 Dₖ 的任一分量作二阶 Taylor 展开。令 d = x − xᵢ、gᵢ = ∇Dₖ(xᵢ)、Qᵢ 为该分量的空间 Hessian，则

Dₖ(x) = Dₖ(xᵢ) + gᵢ·d + ½dᵀQᵢd + O(|d|³)。

单纯形的前两个几何矩为

∫(K) (x − xᵢ) dS = (S_K/N)dΣ，

∫(K) (x − xᵢ)(x − xᵢ)ᵀ dS = S_K[dΣdΣᵀ + Σᵣ dᵣdᵣᵀ]/[N(N + 1)]。

将这两个矩代入 Taylor 式，微面积分成为

∫(K) Dₖ dS ≈ S_K Dₖ(xᵢ) + (S_K/N)dΣ·gᵢ

　　　　　　+ S_K/[2N(N + 1)]·[dΣ·QᵢdΣ + Σᵣ dᵣ·Qᵢdᵣ]。

高效算法用构造顶点处的梯度变化代替显式 Hessian。若该构造顶点的梯度由支撑节点 m 的梯度按几何系数 Cᵣₘ 插值得到，则

Qᵢdᵣ ≈ Σₘ(Cᵣₘ − δᵢₘ)∇Dₖ(xₘ)，

其中 δᵢₘ 在 m = i 时为 1，否则为 0。将它代入上述二阶矩，合并每个节点的梯度项，得到**只依赖几何、可预计算**的向量权重

ℓᵢₘᴷ = (S_K/N)dΣδᵢₘ

　　　+ S_K/[2N(N + 1)]·{dΣ Σᵣ(Cᵣₘ − δᵢₘ) + Σᵣ dᵣ(Cᵣₘ − δᵢₘ)}。

于是逐分量有

∫(K) Dₖ(x) dS ≈ S_K Dₖ(xᵢ) + Σₘ ℓᵢₘᴷ·∇Dₖ(xₘ)。

宏面耗散积分由各微面结果求和，数值通量最终减去其 ½。这里 N 在二维线段为 2，在三维三角微面为 3。对二次多项式 Dₖ 且输入梯度精确时，此几何公式代数精确；对真实 Roe 耗散，Dₖ 是非线性函数，公式只有光滑区域的截断精度，不能称为精确积分。

与可在节点全局缓存的 ∇F(U) 不同，Dₖ 同时依赖一条边的左右重构及该微面的法向。为了使用上式，必须在同一条边的展开点和支撑点构造**两侧迹值与两侧迹梯度**，由前一节的链式法则求 ∇Dₖ；不能直接用全局 `_pointValues[m]` 充当左右两侧。高效模式若没有保存完整的边侧二次重构，便需补充面侧延拓或相应系数。限制器或正性修正介入时，须使用实际参与通量的受限迹，必要时退回现有单次 Roe 或逐微面稳健求积。

## 非共面宏面的额外问题

三维对偶宏面通常由不共面的微三角面组成。当前 `surface.measure` 累加各微面**标量面积**，`surface.vectorMeasure` 累加**有向面积向量**；Roe 使用后者的归一化方向。非共面时一般有 Sₑ > ‖Aₑ‖。即使左右状态在整张宏面上各自恒定，逐微面耗散仍是

I_D,微面 = Σₖ Sₖ B(U_L, U_R, nₖ)(U_R − U_L)，

而当前是 Sₑ B(U_L, U_R, nₑ)(U_R − U_L)。由于绝对值特征算子对法向并非线性函数，两式一般不相等。完整展开因此还要决定：研究对象是**固定宏面法向的状态变化修正**，还是**连微面法向变化一起恢复**。后者需要保留或重新提供逐微面的法向和相应几何权重，也会增加每边的 Roe 工作量。

## 建议的验证顺序

1. 对随机物理状态先核对 Δp 割线恒等式、特征波重构 ΔU、Roe 割线性质，以及紧凑耗散式与现有 `Gas.hpp` Roe 内核的一致性。
2. 远离 `abs`、`max` 分支切换点，分别扰动左右迹值与梯度，比较解析 D′ 和中心差分；在切换附近只检查通量连续性及回退行为，不以经典导数作验收。
3. 在相同左右重构上单独提取传统面积求积的耗散积分，作为参考；保持中心物理通量不变，避免把两种误差混在一起。另用二次向量多项式检验微分权重的代数精确性。
4. 先在平面宏面比较现有冻结公式、固定法向的高阶耗散积分，量化状态变化项。
5. 再在翘曲宏面加入逐微面法向，量化几何法向项；使用左右常状态测试先排除重构误差。
6. 对光滑斜向熵波、等熵涡及跨声速/激波算例，分别记录守恒、误差、非物理状态数、Roe 求值次数和每边耗时。现有高效变分路径在光滑斜向熵波上已报告约三阶，不能预先把精度差异全部归因于耗散积分；参见 [`ncfv_efficient_variational_accuracy_20260922.md`](ncfv_efficient_variational_accuracy_20260922.md)。
