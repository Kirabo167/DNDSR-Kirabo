## Resulting pressure convention

Two-equation ACM defaults to static pressure `p`. Riemann states temporarily use
`p + (2/3)rho*k`, so isotropic stress enters both momentum and continuity
dissipation exactly once. `includeIsotropicStress=false` retains the legacy
modified-pressure convention. Laminar/SA pressure is unaffected by a k stress.
The unified RANS output includes `TurbulentPressure=(2/3)rho*k`.

GPU implementation includes:

- Static-pressure boundary ghosts for reconstruction, closure gradients,
  limiting, viscous corrections and CFL evaluation. No-slip boundaries
  extrapolate total normal stress, avoiding a pressure-dissipation mass flux
  caused by reflected k.
- Effective pressure states in the production face flux and finite-difference
  flow Jacobian, using limited reconstructed k with frozen slopes.
- Device face derivatives with respect to conservative rho*k in the unified
  linear operator, including their effect on shared scalar volume flux.
  The preconditioner retains main's approximate block-triangular structure.
- Static geometric offsets in variational boundary samples; k evaluation and
  all state-dependent boundary/stress/Jacobian operations execute on CUDA.
- The ACMGPU host reference receives the matching CPU changes, retaining its
  explicit prohibition on host CFD residuals in CUDA mode.

CPU changes to constant- and variable-density ACM, schemas and tests are
incorporated from main. This does not add a variable-density resident GPU solver.

## Legacy field conversion

Old field files storing `p*` can request `restartSettings.pressureIsModified=true`
with explicit stress enabled. Initialization computes `p = p* - (2/3)rho*k` using
the loaded turbulence field, before resident state export. Missing k is rejected
rather than inferred from the configured initial state. The seven historical
SUBOFF restart configurations explicitly request this conversion because their
fixed source files predate this change. For newly produced static-pressure
checkpoints, set the flag to false; conversion is not inferred from field names.
No saved field file is edited by the conversion.
