# 完整 GPU 迁移验收

状态：全 GPU 显式数值路径、三维保守 SST/BDF2/LU-SGS 路径已通过验收；CPU 全功能迁移尚未完成。
原 `FluxBatch` 混合运行接入已删除。
CPU 基线保持 `3e7cb94` 加原有本地改动，禁止为迁移修改冻结 CPU 算法。

目标：CPU 只负责配置、网格/静态算子预处理、CUDA/MPI 调度和文件读写。
每个时间步的状态、重构系数、梯度、限制器、残差、步长和阶段历史留在显存；
重构、限制器、边界、黏性/无黏通量、残差装配、归约、时间推进及隐式运算必须在 GPU 执行。
日志允许读取少量归约标量，输出/重启允许下载场数据。GPU 路径禁止静默回退 CPU。

已实现：

- NCFV 静态几何/模板导出及设备常驻数组。
- NCFV 重构、格点恢复、全部限制器、通量、边界和步长 CUDA 内核。
- NCFV 设备侧 SSPRK3、物理性检查和重试。
- 设备 halo 打包与 MPI 交换；通信中转与 CPU 数值计算分别统计。
- ACM 静态 CFV 算子导出、重构和限制器内核。
- ACM 边界、黏性通量、谱半径及 SSPRK3 显式时间推进。
- 数值对照、输出与最终重启保存、设备内存检查、Nsight 活动审计脚本。

通信：单卡全部场数据驻留显存；多卡设备打包/解包，普通 MPI 通过固定页主存缓冲区中转。
CPU 不参与 CFD 数值计算。CUDA-aware MPI 可直接使用设备缓冲区。
本机跨 NUMA 强制 P2P 未通过稳定性验收，手写 IPC/NCCL 路径已移除。

尚未迁移或验收：

- ACM 通用隐式/GMRES、其他 RANS 模型、特征 WBAP/CWBAP、变分重构 GMRES、自适应稳态控制。
- NCFV 非 Roe 通量与特殊诊断接口。
- 400×400×10 全推进时段 GPU 性能与影片输出；当前记录为功能和数值正确性验收。

所有未迁移配置必须显式报出不支持，不能继续运行旧混合路径并称为完整 GPU 版。
