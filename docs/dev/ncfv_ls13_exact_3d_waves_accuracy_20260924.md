# LS13 高效 NCFV：其他三维精确解的精度验证（2026-09-24）

## 算例与设置

使用两种严格三维、光滑、无源、全周期 Euler 精确解，
与等熵涡一样采用三棱柱 IV10/20/40/80 网格、
LS 二次重构且实际模板为 13 点、`EfficientDifferential`、
标准 Roe（程序内熵修正）、无限制器和固定全局步长
0.2/0.1/0.05/0.025。均推进到 \(t=1.6\)，对应 8/16/32/64 步，
MPI 进程数为 1/4/8/32。

令 \(k=2\pi(1/10,1/10,1/4)\)，背景速度 \(U_0=(1,1,0)\)，
\(\theta=k\cdot x-(k\cdot U_0)t\)，扰动幅度为 0.2。

1. **斜向熵波：** \(\rho=1+0.2\sin\theta\)，\(u=U_0\)，\(p=1\)。
   这检验三维斜向密度接触模态。
2. **斜向横向涡量波：** \(\rho=p=1\)，
   \(u=U_0+0.2e\sin\theta\)，其中 \(k\cdot e=0\) 且 \(e\) 的三个分量
   均非零。这是有限振幅的精确非线性 Euler 解，检验三维动量、能量和压力耦合。

两种解析解的周期状态不匹配量分别约为 \(2.2\times10^{-16}\)
和 \(8.9\times10^{-16}\)，没有等熵涡最小镜像截断的尾部拼接。
高效法使用解析点值加解析一阶导数恢复量初始化，
与等熵涡的高效初始化方式一致。
控制体均值参考用每个微四面体 24 点规则计算，
误差用节点对偶控制体体积加权；相邻观测阶按
\(h=(400/N_{\rm node})^{1/3}\) 计算。

## 与等熵涡的关系

同一 LS13 高效格式在等熵涡 40→80 的密度均值阶数为 2.740，
而两个光滑周期三维精确波分别为 2.981 和 2.965。
这说明当前实现具有约三阶的三维收敛能力；
等熵涡的较慢收敛与涡核的旋转、压力平衡、强梯度及 Roe 修正
形成的具体误差组合有关，不能概括为所有三维问题的模板/ghost 缺陷。
两种波也使用 Roe，因此“使用 Roe”本身并不必然导致低于三阶；
Roe 修正作用在等熵涡左右重构面均值跳跃上的误差常数才是前述
等熵涡消融试验定位到的主因。

本测试只覆盖光滑周期 Euler 波；它不证明激波稳定性或更细网格的
严格渐近极限。程序在
`docs/dev/ncfv_ls13_exact_3d_waves_probe.cpp`，生产求解器未修改。

复现示例（从项目根目录编译、从 `build/` 运行）：

```bash
venv/bin/python cases/NCFV/diagnostics/compile_reconstruction_probe.py \
  --source docs/dev/ncfv_ls13_exact_3d_waves_probe.cpp \
  --output /tmp/ncfv_ls13_exact_3d_waves_probe
cd build
HWLOC_COMPONENTS=-gl,-cuda,-nvml OMP_NUM_THREADS=1 \
  mpirun -np 32 /tmp/ncfv_ls13_exact_3d_waves_probe \
  ../cases/NCFV/NCFV_iv80.json /tmp/ls13_entropy_iv80.json \
  entropy 0.025 1.6 13
```

最后一行把 `entropy` 改为 `vortical` 即为涡量波。
