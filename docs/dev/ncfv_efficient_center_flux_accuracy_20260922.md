# 高效 NCFV 中心通量积分精度测试（2026-09-22）

> 历史测试记录：本页数值对应旧实现。当前高效变分使用边中点泛函求完整二次系数，再提取一次导数参加高效通量积分；结果见[新测试报告](../reports/ncfv_efficient_variational_gradient_t1p6_dt_20260928/report.md)。

## 设置与误差定义

等熵涡三棱柱网格 10、20、40、80；时间步长依次为 0.2、0.1、0.05、0.025，计算到 \(t=1.6\)（8、16、32、64 步）。使用高效差分通量积分、15 点二次变分或 LS 重构、无限制器、无黏性和原有 SSPRK3。变分采用 1/4/4/16 MPI 进程，LS 采用 1/4/4/8 进程。

程序中原有的高效内部面通量为

\[
 I_e=\frac{I_{L,e}^{\mathrm{phys}}+I_{R,e}^{\mathrm{phys}}}{2}
 +S_e\left[F_{\rm Roe}(\bar U_L,\bar U_R,n_e)
 -\frac{F(\bar U_L,n_e)+F(\bar U_R,n_e)}{2}\right].
\]

本测试将方括号中的 Roe 修正系数设为零，因此实际用于时间推进的是**左右物理通量高效积分的平均值**，不是“对左右面均值各求一次物理通量再乘面积”。边界通量、重构及 RK3 不变。独立复算的面通量分解与生产程序 RHS 最大不符约 \(1.9\times10^{-13}\)，表明被移除的正是该 Roe 修正项。诊断代码是 `docs/dev/ncfv_efficient_roe_error_budget_probe.cpp`，生产求解器没有修改。

数值密度使用节点对偶控制体储存均值 \(\bar\rho_j\)。参照解析均值由每个微四面体 24 点（六阶精确多项式）求积得到。报告使用体积加权误差

\[
 E_{1,V}=\frac{\sum_j V_j|\bar\rho_j-\bar\rho_j^{\rm exact}|}{\sum_jV_j},\qquad
 E_{2,V}=\left[\frac{\sum_j V_j(\bar\rho_j-\bar\rho_j^{\rm exact})^2}{\sum_jV_j}\right]^{1/2}.
\]

相邻网格的观测阶按 \(h=(400/N_{\rm node})^{1/3}\) 计算，与前次完整 Roe 报告一致。

## 判断

1. 中心通量在这组平滑等熵涡的细网格上显著更准。变分与 LS 的 40→80 密度均值观测阶分别为 4.10 和 3.29；两者都至少表现出三阶以上的**有限网格表观收敛**。
2. 变分重构的 4.10 阶不能宣称格式具有四阶形式精度。二次重构与 RK3 仍是三阶构件，终时刻误差可能含空间、时间及解析周期拼接误差的相互抵消。需要更多网格和时间步细化才能判定渐近阶。
3. 10、20 网格的变分中心通量并非优于 Roe，说明耗散与其他误差有相消效应；不能仅凭细网格改进决定全工况方案。
4. 无耗散中心通量在含激波或间断时没有 Roe 的稳定性保障。本试验是误差归因，不建议直接替代生产 Roe 格式。

复现：从项目根目录构建探针，再从 `build/` 运行，例如 80 网格变分测试：

```bash
venv/bin/python cases/NCFV/diagnostics/compile_reconstruction_probe.py \
  --source docs/dev/ncfv_efficient_roe_error_budget_probe.cpp \
  --output /tmp/ncfv_efficient_center_flux_probe
cd build
HWLOC_COMPONENTS=-gl,-cuda,-nvml OMP_NUM_THREADS=1 mpirun -np 16 \
  /tmp/ncfv_efficient_center_flux_probe \
  ../cases/NCFV/NCFV_iv80.json /tmp/ncfv_center_vr80.json \
  Variational 15 0.025 1.6 0
```

末尾 `0` 指 Roe 修正系数为零；使用 `LeastSquares` 可复现 LS。输出 JSON 同时保存恢复格点误差和均值误差。
